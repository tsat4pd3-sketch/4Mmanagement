# 📬 ESM Mail Ingest — ดึงไฟล์ EDI 830/862 จาก Outlook เข้าคิว ESM

สคริปต์บนเครื่อง user (Windows + Outlook แบบคลาสสิก) เปิดคอมแล้วรันเอง เช็คเมลทุก 15 นาที
เจอเมล `FTM_AAT_830 & 862_*` จากคุณ Sasiyawan → ส่งไฟล์แนบ `830_*.xlsm` / `862_*.xlsm`
เข้าคิว → ไปกด **📥 เปิดเพื่อนำเข้า** ที่แผง 📬 ใน `/planner-sales` แท็บอัพโหลด

รายละเอียดสายงาน/เหตุผลการออกแบบ → `docs/modules/logistic-planner-sales.md` §📬 ดึงไฟล์จากเมล

## ติดตั้ง (ครั้งเดียว)
1. ก๊อปทั้งโฟลเดอร์นี้ไปไว้ในเครื่อง เช่น `C:\ESM\outlook-mail-ingest` (อย่าวางใน OneDrive ที่ sync)
2. ดับเบิลคลิก `install.bat` → วางโทเคนที่ได้จากทีมระบบ → รอขึ้น "ต่อ ESM: ✅ สำเร็จ"
3. เสร็จ — ทุกครั้งที่ login วินโดวส์จะรันเองเบื้องหลัง (ไม่มีหน้าต่าง)

## ใช้งาน / ตรวจ
- `run-test.bat` — ทดสอบต่อ ESM + ลิสต์เมลที่เข้าเงื่อนไข (ไม่ส่งจริง)
- `run-diag.bat` — เจอ 0 ฉบับ? ลิสต์ทุกกล่องเมล + เมลที่ตกเงื่อนไขพร้อมเหตุผล
- `restart.bat` — หลังแก้ `config.ini` หรือเปลี่ยนไฟล์สคริปต์ ให้ตัวเบื้องหลังโหลดใหม่
- `esm_mail_ingest.log` — บันทึกการทำงาน
- `config.ini` — ปรับเงื่อนไขได้ (`folder = Inbox` = Inbox ของ**ทุกกล่อง**ใน Outlook · เจาะกล่องเดียว `ชื่อกล่อง/Inbox` · regex หัวเรื่อง · ผู้ส่ง · ชื่อไฟล์แนบ · ย้อนหลังกี่วัน · ทุกกี่นาที)
- `uninstall.bat` — เลิกใช้

## ข้อจำกัด
- ต้องเป็น Outlook แบบคลาสสิก ("New Outlook" ไม่รองรับ COM)
- ได้ไฟล์เฉพาะตอนคอมเปิด — ปิดเครื่องไปเมลไม่หาย เปิดมาไล่ส่งย้อนหลังตาม `lookback_days`
- ส่งซ้ำไม่ได้: จำเมลที่ส่งแล้วใน `state.json` + ฝั่ง ESM กันซ้ำด้วย Message-ID + ชื่อไฟล์
- โทเคนอยู่ใน `config.ini` เท่านั้น (ไม่เข้า git) · หลุด = แจ้งทีมระบบปิด (`demand_mail_tokens.is_active=false`) แล้วออกใหม่

## 📊 กฎชุดที่ 2 — รายงานบัญชีรายเดือน (เพิ่ม 2026-10-20)

สคริปต์ตัวเดียวกันดูเมล 2 ชนิดแล้ว: `[mail]` = EDI 830/862 เดิม · `[mail.acct]` = ไฟล์ **"01 Report Monthly FS <เดือน>-<ปี> TSAT P4"** จากบัญชี
(มาเดือนละฉบับ ช่วงวันที่ 10-20) · ค่า default อยู่ใน `DEFAULTS['mail.acct']` ของสคริปต์ — ปกติ**ไม่ต้องตั้งอะไรเพิ่ม** แค่ `restart.bat` ให้สคริปต์ใหม่ทำงาน
· เปลี่ยนเงื่อนไขหรือปิดกฎ → เพิ่ม section ใน `config.ini`:

```ini
[mail.acct]
enabled = 1
subject_regex = Report\s*Monthly\s*FS
sender_contains = @thaisummit
attachment_regex = Report.*Monthly.*FS.*\.(xlsb|xlsx|xlsm)$
lookback_days = 45
```

· ไฟล์ชุดนี้ส่งขึ้นคิวเดียวกัน (`demand_mail_inbox`) แต่ติดป้าย `kind = acct` ⇒ **ไม่โผล่ในแผง 📬 ของ /planner-sales** ·
  ตัวที่หยิบไปใช้ = GitHub Actions `acct-import` (ทุกวัน 09:17 ช่วงวันที่ 10-21) เขียนตัวเลขฐาน KPI ทั้งโรงงานใน `/obeya?tab=kpi` ให้เอง
· เมลฉบับเดียวเข้าได้กฎเดียว (กฎแรกที่ผ่านชนะ) · state.json ของกฎนี้ใช้คีย์ `acct:<message id>` — ของ EDI เดิมไม่เปลี่ยน
· `run-diag.bat` แสดงว่าแต่ละฉบับเข้ากฎไหน (`✅ [acct] …`) หรือตกเพราะอะไรทั้ง 2 กฎ
