# ส่วน A — ระดับผู้ใช้ (role)

> ⚠️ **role = "ชุดสิทธิ์ใช้ระบบ" ไม่ใช่ตำแหน่งงาน**
> ตำแหน่งจริง (ผู้จัดการฝ่าย / หัวหน้าแผนก / วิศวกร / ช่างเทคนิค) เก็บแยกที่ช่อง **ตำแหน่ง**
> ใช้แสดงตัวตนและพิมพ์ลงเอกสาร **ไม่มีผลต่อสิทธิ์**
> ตัวอย่าง: คน QA ทุกระดับตั้งแต่ช่างเทคนิคถึงผู้จัดการ ใช้ role `qa` เหมือนกัน ต่างกันแค่ตำแหน่ง

## A.1 role ทั้ง 11 แบบ

| role | ชื่อบนจอ | เหมาะกับใคร | เห็นข้อมูลแค่ไหน |
|---|---|---|---|
| `admin` | 🛡️ ผู้ดูแลระบบ | IT / ผู้ดูแลระบบ | **ทั้งโรงงาน + ทุกหน้าเสมอ** (ล็อกไว้ในโค้ด กันตั้งค่าผิดจนตัวเองเข้าไม่ได้) |
| `manager` | 🏭 สิทธิ์ทั้งฝ่าย | ผู้จัดการฝ่าย/โรงงาน | ทั้งโรงงาน (เว้นแต่ตั้งจำกัดส่วนงาน) |
| `supervisor` | 🏢 สิทธิ์ระดับส่วน | หัวหน้าส่วน/แผนก | เฉพาะ **ส่วนงาน** ที่ถูกตั้งไว้ (เลือกได้หลายส่วน) |
| `leader` | 👥 สิทธิ์ระดับไลน์ | หัวหน้ากลุ่ม/หัวหน้าไลน์ | เฉพาะ **ไลน์ตัวเองและไลน์ลูกทั้งหมด** |
| `qa` | ✅ งานคุณภาพ | ทีม QA/QC ทุกระดับ | **ทั้งโรงงาน** (งานคุณภาพข้ามสายผลิต) |
| `mtn` | 🔧 ซ่อมบำรุง | ช่าง MTN / JIG MTN / DIE MTN | ตามส่วนงาน + ทีมช่างที่สังกัด |
| `engineer` | ⚙️ งานวิศวกรรม | ส่วนวิศวกรรม (PE) | ตามส่วนงานที่ตั้ง |
| `planner_store` | 📦 แผนงาน-คลัง | คลัง / วางแผน | ตามส่วนงานที่ตั้ง |
| `sale` | 🚚 ขาย-จัดส่ง | ทีมขาย / จัดส่ง | ตามส่วนงานที่ตั้ง |
| `document_control` | 🗂️ งานเอกสาร | ควบคุมเอกสาร | ตามส่วนงานที่ตั้ง |
| `display` | 📺 จอแสดงผล | จอ TV / บอร์ดหน้าไลน์ | ดูอย่างเดียว ไม่ใช่คน (ไม่มีสิทธิ์บันทึกอะไร) |

> ⚠️ **`engineer` = "ส่วนวิศวกรรม" (หน่วยงาน) ไม่ใช่ "ตำแหน่งวิศวกร"**
> วิศวกรที่ทำงาน PM สังกัดแผนก MTN → ใช้ role **`mtn`** ไม่ใช่ `engineer`

## A.2 🛡️ แอดมินหน่วยงาน — สิทธิ์ชั้นที่ 2

ติ๊กช่อง **"เป็นแอดมินหน่วยงาน"** ที่หน้า *จัดการผู้ใช้งาน* ให้ user คนไหนก็ได้ (ยกเว้น admin/display)

| | คนใช้งานทั่วไป | แอดมินหน่วยงาน |
|---|---|---|
| **เข้าหน้าไหนได้** | ตาม role เดิม | **ตาม role เดิมเท่านั้น (ไม่เพิ่มหน้าใหม่)** |
| **ทำอะไรได้ในหน้านั้น** | ดู/ใช้ ตาม role | **+ แก้ master · ตั้งค่า · อนุมัติ** ที่ติ๊กไว้ในคอลัมน์ 🛡️ |
| **ขอบเขตข้อมูล** | ตาม role เดิม | ตาม role เดิม (ไม่ใช่ admin ระบบ) |

> ⚠️ **จุดที่คนสับสนบ่อยที่สุด**
> แอดมินหน่วยงาน **"เปิดหน้า" ให้ไม่ได้** — ระบบบล็อกไว้ในโค้ด
> ถ้าอยากให้ช่าง MTN เข้าหน้า X ได้ ต้อง **ติ๊กให้ role `mtn` ในแท็บ "การเข้าถึงหน้า"** ก่อนเสมอ
> แล้วค่อยไปเพิ่มอำนาจแก้/อนุมัติให้เขาที่แท็บ "สิทธิ์การทำงาน" คอลัมน์ 🛡️
> (ด้วยเหตุนี้แท็บ "การเข้าถึงหน้า" จึง **ไม่มี** คอลัมน์แอดมินหน่วยงานให้ติ๊ก)

**ตัวอย่างใช้จริง:** `planner_store` เข้า Product Master ได้อยู่แล้วแต่กดแก้ไม่ได้ → ติ๊กแอดมินหน่วยงานให้ → ปุ่มแก้โผล่ทันที

## A.3 ขอบเขตข้อมูล (Scope)

ระบบกรองข้อมูลให้อัตโนมัติ ไม่ต้องเลือกเอง:

- **`leader`** → เห็น **ไลน์ตัวเอง + ไลน์ลูกทุกตัว** (เช่น หัวหน้า GOR เห็น Assy GOR / Laser GOR ด้วย)
- **role อื่น** → เห็นตาม **ส่วนงาน** ที่ตั้งไว้ (ตั้งได้หลายส่วน เช่น PD1 + PD2)
- **`admin` / `qa`** → เห็นทั้งโรงงานเสมอ
- ไม่ได้ตั้งส่วนงานไว้ → เห็นทั้งโรงงาน

> **ข้อยกเว้นตั้งใจ:** หน้า **ผังรวมโรงงาน** (`/factory-map`) ทุกคนเห็นทั้งโรงงาน
> เพราะเป็นจอภาพรวมสำหรับ TV/ประชุม การกรองเหลือไลน์ตัวเองทำให้หมดความหมาย

# ส่วน B — พื้นฐานที่ทุกคนต้องรู้

## B.1 เข้าระบบ

1. เปิดเว็บ → กรอก **อีเมล + รหัสผ่าน**
2. ระบบแจ้งต่างกันระหว่าง *"ไม่พบบัญชีนี้"* กับ *"รหัสผ่านไม่ถูกต้อง"* — อ่านข้อความให้ดี
3. ลืมรหัส → แจ้ง admin ตั้งใหม่ให้ที่หน้า *จัดการผู้ใช้งาน* (ปุ่ม 🔑)
4. เปลี่ยนรหัสเองได้ที่ **ท้าย sidebar → เปลี่ยนรหัสผ่าน**

### ระบบเตะออกเมื่อไหร่

| กรณี | เวลา | ใครโดน |
|---|---|---|
| ไม่ได้แตะเครื่อง (idle) | 30 นาที → เตือน 5 นาที → ออก | ทุก role ยกเว้น `display` |
| หมดกะ | สิ้นกะที่ล็อกอิน + 1 ชม. | `leader`, `supervisor` เท่านั้น |

> กะเช้าล็อกอิน → หมดอายุ 21:00 · กะดึกล็อกอิน → หมดอายุ 09:00 เช้าถัดไป
> **เหตุผล:** เครื่องเช็คชื่อใช้ร่วมกัน กันคนกะใหม่มาเช็คด้วย session ของกะก่อน
> `admin` / `manager` / ออฟฟิศ ไม่โดน (ใช้เครื่องตัวเอง)

## B.2 หาเมนู

- **sidebar ซ้าย** จัด 9 หมวด: ภาพรวม → ฝ่ายผลิต → วิเคราะห์ & รายงาน → พนักงาน & ทักษะ → Logistic-Store → ซ่อมบำรุง → QA/QC → วิศวกรรม (PE) → ตั้งค่า/ฐานข้อมูล
- **ช่องค้นหาบนหัว sidebar** — พิมพ์ชื่อหน้าแล้วเด้งไปเลย
- **`Ctrl + K`** (Mac: `⌘ + K`) — เปิดช่องค้นหาเมนูแบบเร็ว (↑↓ เลือก · Enter ไป · Esc ปิด)
- **"ใช้บ่อย"** — ระบบจำหน้าที่คุณเข้าบ่อยขึ้นบนสุดให้เอง (จำต่อเครื่อง)
- **เห็นเฉพาะเมนูที่มีสิทธิ์** — เมนูที่ไม่มีสิทธิ์จะไม่โผล่เลย ไม่ใช่กดแล้วโดนปฏิเสธ

## B.3 กะและ "วันงาน"

| กะ | เวลา | OT ปกติ |
|---|---|---|
| กะเช้า | 08:00 – 17:30 | 17:30 – 20:00 |
| กะดึก | 20:00 – 07:59 | 20:00 – 22:30 |

> ⚠️ **"วันงาน" ตัดที่ 08:00 ไม่ใช่เที่ยงคืน**
> ทำงานตี 2 ของวันที่ 18 → ระบบนับเป็น **วันงานที่ 17** (กะดึกของวันที่ 17)
> ทุกหน้าใช้กติกาเดียวกันหมด

**ทีม:** A / B หมุนกะสลับกัน · **C กะเช้าตลอด ไม่หมุน**
**ไลน์ลูกตามกะไลน์แม่อัตโนมัติ** เว้นแต่ตั้งเองแยก

### วันหยุด 4 แบบ (ปฏิทินบริษัท)

| ชนิด | ความหมาย |
|---|---|
| วันทำงาน | ปกติ |
| หยุด OT×1.5 / OT×2 | วันหยุดที่มาทำได้ค่า OT — จอง OT ได้ 8 หรือ 10 ชม. |
| **หยุด 75% (ม.75)** | หยุดชั่วคราวเพราะลูกค้าลด order — หยุดได้ค่าจ้าง 75% · ถูกเรียกมาทำ = ค่าแรงปกติ |

> **ม.75 คือ "กำลังสำรอง"** — ระบบวางแผนผลิตจะเรียกใช้วันนี้ **ก่อน** สั่ง OT วันหยุด (ถูกกว่า)

## B.4 ไฟ Andon (สี)

| สี | หมายถึง | ท่าทาง |
|---|---|---|
| 🟢 เขียว | ปกติ | นิ่ง |
| 🟡 เหลือง | ต้องระวัง / รอดำเนินการ | **นิ่ง ไม่กระพริบ** |
| 🔴 แดง | **หยุด/ผิดปกติ ต้องแก้เดี๋ยวนี้** | **กระพริบ** |
| ⚪ เทา | ไม่มีข้อมูล / ยังไม่เปิดกะ | นิ่ง |

> **แดงกระพริบ = เรื่องด่วนเท่านั้น** ถ้าทุกอย่างกระพริบ คนจะเลิกสนใจ
> **หยุดตามแผน** (นับสต๊อก / ไม่มีแผนผลิต / 5ส) **ไม่ทำให้แดง** และไม่ยิงแจ้งเตือน — ไม่ใช่ความเสียหาย

## B.5 แจ้งเตือน

**3 ช่องทาง:**

| ช่องทาง | ได้อะไร |
|---|---|
| 🔔 กระดิ่งในแอป | 4M · ถูก @ ในคอมเมนต์ · เครื่องหยุดด่วน (เรียกช่าง / ค้างเกินเวลา) |
| 📱 Telegram | ตามที่ตั้งไว้ต่อเรื่อง (เช็คชื่อ · ปิดกะ · แจ้งซ่อม · จัดส่ง ฯลฯ) |
| 📲 Push เข้ามือถือ | เรื่องเดียวกับกระดิ่ง — **เด้งแม้ปิดแอป** |

**เปิด Push:** กดกระดิ่ง → ปุ่ม **"📲 เปิด"**
- **iPhone:** ต้อง *เพิ่มลงหน้าจอโฮม* ก่อน (Safari เฉยๆ ใช้ไม่ได้) + iOS 16.4 ขึ้นไป
- **Android / คอม:** ใช้ได้เลย
- 🔔/🔕 ในกระดิ่ง = เปิด/ปิดเสียงตอนเปิดแอปอยู่

**ติดตั้งเป็นแอป:** เปิดเว็บบนมือถือ → เมนูเบราว์เซอร์ → *เพิ่มลงหน้าจอโฮม* → เปิดเต็มจอมีไอคอนเอง

## B.6 💬 แจ้งปัญหา / ข้อเสนอแนะ

ปุ่ม **💬** ท้าย sidebar — เจอบั๊ก มีไอเดีย หรือสงสัย พิมพ์ส่งได้เลย

- ระบบเก็บ **หน้าที่คุณอยู่ตอนกดแจ้งให้อัตโนมัติ** ไม่ต้องอธิบายว่าอยู่หน้าไหน
- เลือกประเภท: 🐞 บั๊ก / 💡 ข้อเสนอแนะ / ❓ คำถาม
- **ค้นย้อนหลังได้ ไม่ตกหล่นเหมือนแชท** — admin/manager เห็นทั้งหมดในแท็บกล่องขาเข้า และตอบ/ปิดงานได้

## B.7 มือถือ

- เมนูซ่อนอยู่หลังปุ่ม ☰ มุมบนซ้าย
- ตารางกว้างเลื่อนแนวนอนได้ (นิ้วปัด)
- **ผังไลน์บนมือถือ** — บีบนิ้วซูมได้
- หน้าที่ใช้บนมือถือบ่อย: เช็คชื่อ · Daily Report · แจ้งซ่อม · Daily Checker · รีโมทจอ

# ส่วน C — คู่มือรายหน้า

## 1. ภาพรวม (จอแสดงผล / ผู้บริหาร)

### 1.1 🏠 หน้าหลัก (`/`)
หน้าแรกหลังล็อกอิน — การ์ดโมดูลตามหมวด กดเข้าหน้าที่ต้องการ **เห็นเฉพาะที่มีสิทธิ์**
เต็มจอ ไม่มี sidebar

### 1.2 📊 Dashboard (`/dashboard`)
**จอ TV หน้าไลน์ / จอผู้บริหาร** — realtime

- กำลังคนวันนี้ · PPE ครบ/ไม่ครบ
- บอร์ด Heijunka (คิวงานแต่ละไลน์เป็นแถบเวลา)
- ผังไลน์ + ตำแหน่งพนักงาน (คลิกไลน์ = กางผังใหญ่)
- แผง Andon: เครื่องหยุด · 4M ค้าง · ของเสียวันนี้
- feed 4M ล่าสุด

> ไม่มีหัวเรื่องโดยตั้งใจ — หัวเรื่องกินพื้นที่แนวตั้งบนจอ TV

### 1.3 📋 Dashboard ส่วนงาน (`/dept-dashboard`)
**หน้าเดียว สลับส่วนงานด้วยแท็บ** — ฝ่ายผลิต · ซ่อมบำรุง · สโตร์ · QA

โครงเหมือนกันทุกใบ 4 ชั้น:
1. 🚨 **ต้องทำตอนนี้** — คิวงานค้าง (ว่างก็ต้องขึ้นว่า "ไม่มีงานค้าง" ไม่ซ่อน)
2. 📊 **KPI** — มีตัวเทียบเสมอ
3. 📈 **ชี้เป้าให้แก้** — ตาราง/พาเรโต
4. 🔗 **ทางลัด**

**อ่านอย่างเดียว** — ทุกแถวเป็นลิงก์ไปหน้าที่ทำงานจริง **พาไปถึงตัวงานนั้นเลย** (เช่น 4M รออนุมัติ → กดแล้วเปิดใบนั้นพร้อมกดอนุมัติ)

**ของเด่นแต่ละส่วนงาน:**
- ซ่อมบำรุง → *"เครื่องที่หยุดซ้ำ ≥2 ครั้งใน 30 วัน แต่ยังไม่มีใบแจ้งซ่อม"*
- QA → *"ไลน์ที่เดินกะวันนี้แต่ยังไม่มีบันทึกของเสีย"* (ของดี 100% จริง หรือลืมลง?)

### 1.4 🗺️ ผังรวมโรงงาน (`/factory-map`)
**รูปผังโรงงาน 1 รูป ตีกรอบแต่ละไลน์ ระบายสีตามสถานะ** — จอเดียวเห็นทั้งโรงงาน

### 2.2 📝 เช็คชื่อ & PPE (`/checkin`)
**งานแรกของทุกกะ**

1. เลือกไลน์ (เห็นเฉพาะไลน์ในขอบเขตตัวเอง)
2. ติ๊ก **มา / ลา** รายคน
3. ติ๊ก **PPE** — หมวก · รองเท้า · ถุงมือ ฯลฯ (ตามที่ไลน์นั้นกำหนด)
4. ติ๊ก **OT** ถ้ามี
5. **บันทึก**

> ⚠️ **PPE ไม่ครบ = คนนั้นขึ้นแดงกระพริบ** บนผังไลน์ และ **ไม่ถูกจัดลงจุดงาน** ในหน้าจัดการไลน์

**ปุ่มเดียว 3 งาน — ระบบดูเองว่าคุณเปลี่ยนอะไร แล้วแจ้งให้ตรง:**

| ทำอะไร | Telegram แจ้งว่า |
|---|---|
| บันทึกครั้งแรกของวัน | เช็คชื่อเริ่มงาน |
| แก้คนมา/ลา/PPE ทีหลัง | **อัปเดตกำลังคน** (บอกด้วยว่าใครเปลี่ยน) |
| จอง/แก้ OT | **จองรถ OT** (รายชื่อ + งาน + เวลา) |
| กดบันทึกโดยไม่เปลี่ยนอะไร | **เงียบ ไม่แจ้ง** |

**จอง OT วันหยุด** — เลือกช่วงได้ 4 แบบ: เช้า 8 ชม. / เช้า 10 ชม. / ดึก 10 ชม. / ดึก 8 ชม.

**📄 พิมพ์ได้ 2 ใบ:** ใบชดเชย-OT · ใบบันทึกการมาทำงาน

### 2.3 🔄 จัดการไลน์ผลิต (`/management`)
**จัดคนลงจุดงานบนผังไลน์จริง** (ลากวาง)

- ลากคนจาก pool ลงจุดงาน → ระบบคิด **% ความเหมาะสม (Skill Fit)** ให้ทันที
  🟢 80%+ · 🟡 60-79% · 🟠 40-59% · 🔴 ต่ำกว่า 40%
- **ย้ายคนข้ามจุด/ข้ามไลน์ → ระบบสร้าง 4M (Man) ให้อัตโนมัติ** เข้าคิวอนุมัติ
- คนที่ PPE ไม่ครบขึ้นแถบเตือนเหนือผัง (ไม่เข้า pool ให้ลาก)
- คนที่ย้ายจุดแล้ว 4M ยังไม่อนุมัติ = จุดเหลือง (นิ่ง)

> ต้องมีสิทธิ์ *จัดกำลังคน* ถึงจะลากได้ · ไม่มีสิทธิ์ = ดูอย่างเดียว

### 2.4 📊 Daily Report (`/daily-report`)
**หัวใจของงานผลิตรายวัน** — แท็บ: ⚡ สด · 📜 ประวัติ · ⚙️ ตั้งค่า

#### เปิดกะ
เลือกไลน์ + กะ → เปิด · ระบบจับเวลาให้

#### เปิดใบงาน 2 แบบ

| แบบ | ใช้เมื่อ | ปิดยังไง |
|---|---|---|
| **สแกน Kanban** | มีบาร์โค้ด | **ต้องสแกนปิดเท่านั้น** (ไม่มีปุ่มปิดมือ — รักษาการสอบกลับ + ยอดเข้าคลัง) |
| ✍️ **เปิดเป้า (ไม่มีบาร์โค้ด)** | ไลน์ที่ไม่มี kanban card | ปุ่ม **✓ ปิดใบนี้ (ยอดจริง)** |

- **⏪ เปิดย้อนหลังได้** (บังคับกรอกเวลา · ห้ามกรอกเวลาที่ยังมาไม่ถึง)
- **งานคู่ RH/LH** — เปิดใบเดียว ระบบถามแล้วเปิดคู่ให้อัตโนมัติ (แม่พิมพ์คู่ปั๊มครั้งเดียวได้ทั้ง 2 ข้าง)
- ไลน์เครื่องขนาน — เลือกเครื่องตอนเปิดใบได้

#### กรอกยอดระหว่างกะ (แนะนำ)
ทุกช่วงเบรค กรอก **ยอดสะสม** ในการ์ดใบงาน — **ใบสแกนก็กรอกได้ ไม่บังคับ**

> กรอกแล้วการ์ดเปลี่ยนเป็น *"ทำได้/เป้า"* + บอก **"➡ ปิดกะตอนนี้ ยกไป N ชิ้น"**
> ทำให้เห็นยอดที่จะส่งต่อกะหน้าตั้งแต่ระหว่างกะ ไม่ต้องไปเปิดดูกะถัดไป
> มีแบนเนอร์รวมด้วย: **"⏭ จะส่งต่อกะหน้า ~X ชิ้น"** (ใบที่ยังไม่กรอกนับเต็มใบไว้ก่อน + เตือนสีเหลือง)

#### Downtime (เครื่องหยุด)
- เลือกประเภท → กรอกเวลาเริ่ม-จบ **หรือ** กรอกแค่จำนวนนาที
- **เครื่องจักรและชิ้นงานไม่บังคับ** (หลายเรื่องหยุดทั้งไลน์: รอวัตถุดิบ · ไฟดับ · ประชุม · 5ส)
  แต่ถ้าเป็น *เครื่องเสีย* แล้วไม่เลือกเครื่อง ระบบจะ **ถามยืนยันก่อน**
- **ประเภทที่ชื่อมีคำว่า "อื่น" → บังคับกรอกรายละเอียด** (ไม่งั้นรายงานอ่านไม่รู้เรื่อง)
- **📷 สแกน QR เครื่อง** ได้ (เตือนถ้าเครื่องอยู่คนละไลน์)
- ปุ่ม **📞 เรียกช่าง** → แจ้งช่างทันที + ไซเรนดังหน้า MTN
- **ไม่ปิดรายการ + เกินเวลาที่ตั้งไว้ (default 15 นาที) → แจ้งเตือนอัตโนมัติ + ไซเรนหน้าผลิต**
- ปุ่ม **📝 เปิดใบซ่อม** → สร้างใบ MO ให้เลย

#### ของเสีย (NG)
เลือกประเภท + จำนวน + หมายเหตุ · ประเภท "อื่นๆ" บังคับกรอกรายละเอียดเช่นกัน

#### ปิดกะ
1. หัวหน้ากลุ่มกด **📋 ขอปิดกะ** — กรอก **หมายเหตุของผู้ขอ** ได้ (เช่น *"ยอดไม่ถึงเพราะรอ material ตั้งแต่ 14:00"*)
2. ยอดที่กรอกไว้ระหว่างกะถูกเติมให้ในช่อง "ยอดจริง" อัตโนมัติ (แก้ทับได้)
3. เครื่องยังซ่อมไม่เสร็จ → เลือก **"ยังซ่อมอยู่ — ตัดยอดข้ามกะ"** (กะถัดไปสร้างรายการต่อให้เอง)
4. **หัวหน้าส่วนตรวจ** → ✅ อนุมัติ (ใส่หมายเหตุได้) หรือ **✕ ปฏิเสธ (บังคับบอกเหตุผล)**
5. ถูกปฏิเสธ → กะกลับมาเปิด + **แบนเนอร์แดงบอกว่าต้องแก้อะไร** + ลิสต์กะขึ้นชิป **"✏️ ต้องแก้"**

> **↩️ ถอยใบที่สแกนปิดไปแล้ว** ได้ เฉพาะตอนกะยังเปิด (ปิดกะแล้วถอยไม่ได้)
> การ์ดจะโชว์ **"↩️ เคยถอยใบ N ครั้ง"** ตลอดไป ให้ตรวจย้อนหลังได้
> **🗑 ลบกะเปล่า** ได้ ถ้ายังไม่มีใบงาน/Downtime/ของเสียเลย (สิทธิ์ admin)

#### ⚙️ แท็บตั้งค่า
สินค้า · เครื่องจักร · ประเภท Downtime · ประเภทของเสีย · นโยบายพัก · **กระบวนการผลิต**
> ประเภท Downtime ตั้ง **6 Big Losses / 8 Wastes** ได้ด้วย (ใช้ในแท็บวิเคราะห์สาเหตุ ไม่กระทบ OEE)

### 2.6 ✅ Daily Checker (`/daily-checker`)
**ศูนย์รวมงานเช็ครายวัน** 3 แท็บ (โผล่ตามสิทธิ์)

| แท็บ | คือ |
|---|---|
| 🔧 **AM (Autonomous Maintenance)** | **พนักงานผลิตตรวจเครื่องเองทุกต้นกะ** |
| 🛡️ **Poka-Yoke Check** | ทดสอบอุปกรณ์กันพลาดด้วยชิ้น master NG |
| 📋 **LPA** | Layer Process Audit (FM-QMR-008) |

> ⚠️ **AM ≠ PM**
> **AM** = ฝ่ายผลิตตรวจเอง **ทุกต้นกะ** · **PM** = ช่างตรวจ **ตามรอบเวลา/ยอดผลิต**
> คนละคน คนละทะเบียน คนละสิทธิ์

**ลำดับตั้งค่า AM ที่ถูกต้อง:**
`PM Setup` ลงจุดตรวจ → `Daily Checker ⚙️` ติ๊กลงทะเบียน → **เครื่องถึงโผล่ให้ตรวจ**
> ลงจุดตรวจแล้วแต่ยังไม่ลงทะเบียน → มีบล็อกส้มบอกให้ไปลงทะเบียน **ไม่เงียบ**

#### 📋 LPA (แท็บย่อย)

## 3. วิเคราะห์ & รายงาน

### 3.1 📈 OEE (`/oee-analytics`)

#### OEE คืออะไร
`OEE = A × P × Q`

| | ชื่อ | ตอบว่า |
|---|---|---|
| **A** | Availability | เครื่องเดินได้กี่ % ของเวลาที่ตั้งใจให้เดิน |
| **P** | Performance | เดินเร็วเท่ามาตรฐานมั้ย |
| **Q** | Quality | ของที่ออกมาดีกี่ % |

> ⚠️ **ยอดที่สแกนปิดใบ = "ของดี" ล้วน** ของเสียถูกผลิตเพิ่มจนได้ของดีครบแล้ว
> `Q = ของดี ÷ (ของดี + ของเสีย)` — **ห้ามเอาของดีลบของเสีย** (จะได้ค่าต่ำเกินจริง)

#### 3 ตัวชี้วัดที่ต่างกันแค่ "ฐานเวลา"

| | ฐาน | ตอบว่า |
|---|---|---|
| **OEE** | เวลาที่ตั้งใจเดิน (หักพัก + หยุดตามแผน) | ตอนตั้งใจเดิน เดินดีแค่ไหน |
| **OOE** | เวลากะทั้งหมด | เวลาที่เปิดโรงงาน ใช้คุ้มแค่ไหน |
| **TEEP** | ปฏิทิน 24 ชม. | กำลังผลิตทั้งหมดที่มี ใช้ไปกี่ % |

> **TEEP ต่ำ + OEE สูง = ไม่ต้องซื้อเครื่อง เปิดกะเพิ่มพอ** (ใช้ตอนของบลงทุน)

#### "OEE จริง" — ปิดช่องโหว่
ติ๊ก Downtime เป็น *"ในแผน"* แล้ว OEE ไม่ตกเลย → เพิ่ม **OEE จริง** ที่นับหยุดทุกชนิดเป็นการสูญเสีย
> หยุดตามแผนกินเกิน 5% ของฐาน = ขึ้นแถบเหลืองให้ไปตรวจการจัดประเภท
> **ต้นเหตุจริงคือ master data** — แก้ที่ Daily Report ⚙️ ตั้งค่า

#### แท็บในหน้า
- **ภาพรวมวันนี้** — การ์ดกะที่กำลังผลิต (คำนวณ**สด** มีป้าย "· สด")
- **แนวโน้ม** — รายวัน/รายเดือน
- **🧠 วิเคราะห์สาเหตุ** — 7 เรื่องอัตโนมัติ: แตกเป้าที่หาย · Downtime เรื้อรัง · กะเช้า vs กะดึก · วันที่ DT หนักผิดปกติ · คนขาด↔OEE · สินค้าวิ่งช้าซ้ำ · ของเสียกระจุกประเภทเดียว
  + **6 Big Losses / 8 Wastes** พร้อมแนวทางแก้ตามตำรา
- **🧩 เจาะ "อื่นๆ"** — จับกลุ่มหมายเหตุที่พนักงานพิมพ์เอง แล้วชวนไปตั้งเป็นประเภทของตัวเอง
- **📽️ รายงานเดือน** — สร้างเด็ค PowerPoint ตาม template TSG อัตโนมัติ
- **🎯 ตั้งเป้า A/P/Q** รายกลุ่มไลน์ (เป้า OEE ไม่ตั้งเอง คำนวณจาก A×P×Q เสมอ)

> ⚠️ **ประเมินไม่ได้ ≠ 0%** — ยังไม่ผลิต / ยังไม่ตั้ง cycle time → ขึ้น "—" พร้อมบอกเหตุผล **ไม่แสดง 0%**
> ตั้ง CT ไม่ครบทุกชิ้นงาน → %P ต่ำกว่าจริง จะมีป้าย **⚠ CT ไม่ครบ** เตือน

- **🏭 อุปกรณ์ที่ใช้ผลิต** — เครื่อง/แม่พิมพ์ **ขาด PM ตอนนั้นมั้ย · ใครแตะล่าสุด**
  > ⚠️ คำนวณย้อนจากประวัติจริง **ไม่ใช่อ่านสถานะปัจจุบัน** (ช่างทำ PM หลังผลิต ค่าจะขยับไปแล้ว)
  > ไลน์ไหลทีละชิ้น = **ผ่านทุกเครื่องจริง (ยืนยัน)** · ไลน์เครื่องขนานที่ไม่ระบุเครื่อง = **ผู้ต้องสงสัย ไม่ใช่ข้อสรุป**
- **⏱️ วิเคราะห์การวิ่ง** — วิ/ชิ้นจริง vs มาตรฐาน
  > ⚠️ พนักงานสแกนเป็นชุด → ระบบตรวจเจอแล้วขึ้น **"สแกนเป็นชุด N ใบ"** และคิดความเร็ว **ระดับกลุ่ม** แทน (รายใบใช้ตัดสินไม่ได้)
- **🔍 ลูกค้าแจ้งอาการอะไร** — เลือกอาการจาก PFMEA → ระบบชี้จุดที่ต้องสงสัยเป็น **3 ขาแบบ 8D** (เกิดขึ้นได้ยังไง / ทำไมตรวจไม่เจอ / ระบบพลาดตรงไหน)
  > อาการที่ไม่เคยมีใน PFMEA → ขึ้นแถบส้มว่า **"ไม่เคยถูกคาดไว้ตอนออกแบบ"**
  > **ระบบเสนอจุดต้องสงสัย ไม่ใช่ยืนยันสาเหตุ**

> เวลาแต่ละเฟสนับถอยหลังจากเวลาส่ง (default −240 / −120 / −60 / 0 นาที) ปรับรายลูกค้าได้

**สี:** 🟢 stock พอ · 🟡 ขาดบางส่วน · 🔴 **ไม่มี stock ต้องผลิต!**

> ⚠️ หักไม่ได้/ได้ไม่ครบ → **ขึ้น toast แดงบอกสาเหตุ** (จับคู่เลขไม่ได้ = แก้ master · จับคู่ได้แต่ไม่มีของ = เช็คการปิดใบผลิต) **ไม่กลบด้วย toast เขียว**

**➕ เพิ่ม order ด่วน** — ลูกค้าโทรสั่งนอกไฟล์ EDI คีย์เองได้ (ไม่ถูกทับตอนอัปโหลดซ้ำ)

#### 📥 นำเข้าจาก Excel (ไม่ต้องพิมพ์ใหม่)

- อ่านหัวเอกสารเอง → เติม Part No. / Model / ลูกค้า / เลขเอกสาร ให้
- **โหมด:** สร้างชุดใหม่ / เติมทับชุดเดิม (แทนที่รายการ แต่**ไม่ลบ OP เดิม** — ค่าที่คนแก้ไว้ไม่หาย)
- ไฟล์เดียวก็นำเข้าได้ (ขาดอะไรจะบอกให้ไปเติม)
- **เลข OP ในเซลล์ไม่ตรงชื่อแท็บ → ยึดชื่อแท็บ แก้ให้ แล้วยังเตือน** ให้ไปแก้ไฟล์ต้นทาง
- layout ที่ระบบไม่รู้จัก → **ได้ 0 รายการ + บอกว่าคาด layout แบบไหน** (ไม่ยอมนำเข้าข้อมูลมั่ว)

#### ⬇️ ดาวน์โหลด Excel
**PFMEA / Control Plan** — สร้างไฟล์ใหม่จากข้อมูลในระบบ (RPN เป็นสูตร ไม่ใช่ค่าคงที่)
> ⚠️ **PFC (ผังกระบวนการ) ดาวน์โหลดไม่ได้** — เป็นผังที่วาดด้วยรูปทรงใน Excel ไม่ใช่ตาราง
> ส่วนที่ต่างจากไฟล์เดิม ~5% **ระบบขึ้นบอกบนจอทุกครั้ง** (กล่องข้อความที่วาดทับ · เส้นขอบที่แก้มือ · ช่องที่ระบบยังไม่มีข้อมูล = ปล่อยว่าง ไม่เดา)

#### 🗺️ ผังกระบวนการที่ระบบวาดเอง
อยู่เหนือตาราง OP ในแท็บ Flow — **generate จากข้อมูล แก้ OP แล้วเปลี่ยนตามทันที**
- สัญลักษณ์ ASME + legend · พิมพ์ A3 แนวนอน **บังคับลง 1 หน้า**
- **ตัวหนังสือเล็กเกินอ่าน → ขึ้นเตือน** (ไม่ปล่อยให้ไปเจอเองตอนพิมพ์)

> ⚠️ **คนละสิ่งกับไฟล์ PFC ต้นฉบับ** — ตัวจริงคือเอกสารควบคุมที่ PE วางเองใน Excel (มีข้อความกำกับบนจอและบนใบพิมพ์)

## 9. ตั้งค่าโปรแกรม, ฐานข้อมูล

### 9.1 🏢 แผนผังองค์กร (`/org-setup`)
ผัง **ส่วนงาน → แผนก → กลุ่ม/ไลน์**
- แผนกที่ไม่ขึ้นกับส่วนงานไหน → เลือก **"🏛️ ขึ้นตรงฝ่าย"**
- ตั้ง **ประเภทแรงงาน** Direct / Indirect ได้ทั้งระดับส่วนงานและแผนก
- **💰 Activity Rate** — ค่าแรง/โสหุ้ย/ค่าเสื่อม (บาท/ชม.) ต่อ cost center
  > กรอกที่ **ระดับกลุ่ม (21406…) เท่านั้น** — ระดับบนรวมขึ้นให้เอง
  > เก็บแบบ **มีผลตั้งแต่วันที่** (ปรับรายปีได้ ไม่ทับประวัติ — โปรเจคเก่าใช้ rate ณ วันเริ่ม)

### 9.2 🔩 Product Master (`/products`)
สินค้า · BOM · Kanban Standard · Packaging · **🗂 Parts Master** · **🔀 Routing**

> **`parts_master` = ทะเบียนกลางของทุก MAT** — ตัวตนสินค้า (เลข · ชื่อ · หน่วย · จำนวน/กล่อง · supplier · ต้นทุน · รูป) อยู่ที่นี่ที่เดียว
> **ลำดับที่ถูก: ลง Parts Master ให้ครบก่อน → หน้าอื่น "เลือก" ไม่ใช่ "พิมพ์ใหม่"**
> ฟอร์มสินค้ามีปุ่ม **🗂 เลือกจาก Parts Master** · พิมพ์เลขที่ไม่มีในทะเบียน = **เตือนสีส้ม (ไม่บล็อก)**

- **🔄 EC (Engineering Change)** — บันทึกแล้ว: สร้างสินค้าใหม่ + mark ตัวเก่าถูกแทน + **ลงทะเบียน MAT ใหม่ให้อัตโนมัติ**
  > สืบทอดเฉพาะ**คุณสมบัติกายภาพ** (หน่วย/จำนวนต่อกล่อง/supplier/รูป) — **ต้นทุนไม่สืบทอด** (rev ใหม่ต้นทุนเปลี่ยนได้ ให้บัญชีเติม)
  > **ต้องตามไปตั้งเองกับ MAT ใหม่:** BOM · Kanban Std · Packaging · Routing และควรออก revision ที่ `/pe-docs`
- **🔩 รายการขั้นตอน (OP)** — สร้างเฉพาะขั้นที่ **อยากมอนิเตอร์แยก** (เครื่อง stand-alone / งาน semi)
  > ⚠️ สร้าง product ให้ sub process เมื่อไหร่ **ต้องติ๊ก 🔩 เสมอ** ไม่งั้นยอดถูกนับซ้ำ
  > งานที่ไหลจบในใบพาร์ทจริง = **ไม่ต้องสร้าง OP**
- **📥 นำเข้า CSV ต้นทุน** — เซลล์ว่างไม่ล้างค่าเดิม

### 9.3 🗺️ ตั้งค่าผัง/Floorplan (`/layout-setup`)
**ที่เดียวสำหรับการแก้ผังทุกชนิด** 4 แท็บ

| แท็บ | แก้อะไร |
|---|---|
| 🗺️ **ภาพรวมโรงงาน** | อัปรูปผังใหญ่ + วาดกรอบไลน์ (รูปทรงอิสระ รองรับ L/U shape) |
| 🏭 **ผลิต** | ผังไลน์ + จุดงาน (ลิงก์ไป Line Setup) |
| 🔧 **MTN** | ผังเครื่องจักร + โซน facility |
| 📦 **Store/AMR** | **วาดถนน/ทางเดินรถ** |

**วาดถนน:** ✏️ วาดต่อเนื่อง (คลิกไล่ตามถนน) · เพิ่มจุดเดี่ยว · เชื่อม 2 จุด · ย้าย · ลบ
> **ถนน 2 เส้นตัดกัน = ระบบใส่สี่แยกให้เอง** · วางจุดบนถนนเดิม = สามแยก
> **📏 ตั้งมาตราส่วน** — คลิก 2 จุดที่รู้ระยะจริง กรอกเมตร → ระยะ/เวลาเป็นหน่วยจริง

### 9.4 🏭 ฐานข้อมูลเครื่องจักร (`/machine-database`)
ทะเบียนอุปกรณ์ทั้งหมด

> **default กรองเฉพาะ "เครื่องจักร"** — ไม่งั้นแม่พิมพ์ 262 ตัวปนในลิสต์/สถิติ
> สลับดูชนิดอื่นได้จากแถบกรอง

- **หมวด:** 🏭 ไลน์ผลิต / 🔧 Facility (เลือก Facility → ช่องไลน์เปลี่ยนเป็น "ระบบ/พื้นที่")
- **ลักษณะเครื่อง:** ระดับอัตโนมัติ (manual / semi / auto) · รูปแบบเดินเครื่อง (เดี่ยว / gang / inline)
- **🔗 Supply route** — เครื่อง facility จ่ายให้ไลน์ไหนบ้าง (ใช้เตือนตอนซ่อม/ตัดไฟ)
- กลุ่มไลน์ย่อ/ขยายได้

### 9.5 🔨 ทะเบียนแม่พิมพ์ (`/die-registry`)
มุมมองแม่พิมพ์ — จัดกลุ่มเป็น **ชุด (1 พาร์ท = 1 ชุด)** → กางดูรายขั้น (OP / ตัน / shot สะสม / จำนวนครั้งที่เจียร)

- **แถบ "ข้อมูลที่ยังต้องเก็บให้ครบ"** + ปุ่ม 🔎 ดูเฉพาะที่ต้องแก้
  > ข้อมูลมาจากการแกะชื่อเครื่องเดิม ช่องที่แกะไม่ออกปล่อยว่าง **ห้ามซ่อน**
- **OP ซ้ำในชุด = สัญญาณว่าเป็นหลายชุดที่ถูกรวมกัน** — ระบบชี้ให้เห็น **ไม่แยกให้เอง**
- **แก้ shot สะสมไม่ได้** (เป็นตัวนับจากการผลิต ไม่ใช่ค่าที่คนพิมพ์ทับ)

### 9.6 🏭 กระบวนการผลิต (`/process-setup`)
เพิ่ม/แก้กระบวนการ (เชื่อมประกอบ · ปั๊มขึ้นรูป · เลเซอร์ · ดัด ฯลฯ)
> เพิ่มแล้วไปติดป้ายให้เครื่อง/สินค้า → dropdown ทุกจุดเห็นเอง ไม่ต้องแก้โปรแกรม

### 9.7 🏷️ พิมพ์ป้าย QR (`/qr-labels`)
เลือกเครื่องจักร/จิ๊ก → กรองไลน์ + ค้นหา → ติ๊ก → **พิมพ์สติกเกอร์ A4** (3 ขนาด: 40×25 / 60×40 / 90×60 mm)

ป้ายมี **QR + เลขเครื่องตัวใหญ่ + ชื่อ + ไลน์** (คนอ่านเลข เครื่องอ่าน QR)
> **1 อุปกรณ์ = 1 ป้ายเท่านั้น** — เครื่องจักรพิมพ์จากแท็บเครื่องจักรทางเดียว (ระบบกรองรายการซ้ำออกให้ + บอกว่าซ่อนไปกี่รายการ)

**สแกนได้ที่:** ฟอร์มแจ้งซ่อม · ฟอร์ม Downtime · เรียกภาชนะ
> ตัวอ่านทน 3 แบบ: QR ของระบบ · **บาร์โค้ดเดิมที่ติดเครื่องอยู่ก่อนแล้ว** · QR แบบลิงก์
> สแกนไม่ติดก็ **พิมพ์มือได้เสมอ** (งานต้องเดินต่อ)

### 9.8 📅 ปฏิทินบริษัท (`/company-calendar`)
วันหยุด/วันทำงาน — มีผลกับ: จอง OT · คำนวณ Kanban · แผนผลิต · แผน PM · LPA
> ตั้ง **หยุด 75% (ม.75)** รายวันได้ (สีม่วง)

### 9.11 📄 ทะเบียนเอกสาร & ฟอร์ม (`/doc-forms`)
**คุมเลขฟอร์ม · Rev · วันบังคับใช้ · ช่องลายเซ็น · footer · โลโก้ · Legend · ผู้ออกเอกสาร · ประวัติแก้ไข ของเอกสารทุกใบ**

**แก้ที่นี่ ใบพิมพ์ใช้ทันที ไม่ต้องแก้โปรแกรม** (24+ ฟอร์ม)

- **🖨️ ทดลองพิมพ์ได้จากทะเบียนเลย** — ใบตัวอย่างมี **ลายน้ำ "ตัวอย่าง" + แถบเตือน** กันเอาไปใช้แทนใบจริง
- **✍️ ชุดช่องลายเซ็นแยกรายส่วนงานได้** — เลขฟอร์ม/Rev เป็นของบริษัท (ชุดเดียว) แต่ป้ายช่องเซ็น + ชื่อผู้เซ็น + footer แยกตามส่วนงานได้
  > **จำนวนช่องล็อกตาม layout เปลี่ยนได้แค่ข้อความ**
- **บางฟอร์มล็อกขนาด/แนวกระดาษ** (ตารางกว้างตามจำนวนวัน เปลี่ยนแล้วใบพัง) — ระบบ**อธิบายเหตุผลบนจอ ไม่ปล่อยให้กดแล้วเงียบ**

สร้าง/แก้/ลบ user

- **🔑 ตั้งรหัสผ่านใหม่** ให้คนที่ลืมรหัส (ใช้กับบัญชี admin ไม่ได้)

### 9.13 📜 ประวัติการแก้ไขข้อมูล (`/audit-log`)
**จอกลางดูว่าใครแก้อะไร เมื่อไหร่ ค่าเก่าเป็นอะไร** — ครอบตารางที่บันทึกประวัติไว้ทั้งระบบ (~74 ตาราง)

> ⚠️ **เก็บย้อนหลัง 6 เดือน** แล้วระบบลบอัตโนมัติ — ต้องเก็บนานกว่านั้นให้ **export ออกก่อน**

## การอัปเดตเอกสารนี้

**เอกสารนี้เป็นคู่มือใช้งานฉบับหลักฉบับเดียว** (`docs/WORK_INSTRUCTION.md`)
— ถ้าจะเขียนคู่มืออีกฉบับ ให้ถามก่อนว่าทำไมถึงไม่แก้ฉบับนี้

### เมื่อไหร่ต้องอัปเดต
- เพิ่มหน้าใหม่ / ลบหน้า / ย้ายหมวด → ส่วน C + ส่วน D
- เปลี่ยนขั้นตอนการทำงาน (workflow) → ส่วน C ของหน้านั้น
- เพิ่ม role / เปลี่ยนสิทธิ์ตั้งต้น → ส่วน A + ส่วน D
- เปลี่ยนกติกากลาง (กะ · วันงาน · Andon · แจ้งเตือน) → ส่วน B

### วิธีตรวจว่าครบ
```bash
# หน้าที่มีในเมนู แต่ยังไม่มีในคู่มือ
grep -oE "to: '/[a-z0-9-]*'" src/App.jsx | sed "s|to: '||;s|'||" | sort -u > /tmp/nav.txt
grep -oE '`/[a-z0-9-]*`' docs/WORK_INSTRUCTION.md | tr -d '`' | sort -u > /tmp/wi.txt
comm -13 /tmp/wi.txt /tmp/nav.txt      # ว่าง = ครบ
```

> อัปเดตเลขแล้ว **รัน `python3 docs/build_infographic.py`** แล้วสร้าง PDF/PNG ใหม่

> สร้างใหม่ (ทั้ง 2 ภาษา):
> ```bash
> python3 docs/build_infographic.py          # หรือใส่ en / th เพื่อทำทีละภาษา
> for f in ESM_Overview_Infographic_A4 ESM_Overview_Infographic_A4_TH; do

>     --print-to-pdf=docs/$f.pdf file://$PWD/docs/$f.html

> ```
>
> ⚠️ **กับดักภาษาไทย** (แก้ไว้แล้วในตัวสร้าง — ห้ามถอด):
> `letter-spacing` ทำสระ/วรรณยุกต์ลอย · `line-height` ต่ำกว่า 1.45 ตัวบนโดนตัด ·
> ตัวไทยดูเล็กกว่าอังกฤษที่ pt เท่ากัน (ฉบับ TH ขยายฟอนต์ให้แล้ว) ·
> ป้ายรอบวงแหวนภาษาไทยยาวกว่า **ต้องวัดว่าไม่ล้นออกนอก viewBox** ไม่งั้นไปทับคอลัมน์ข้างๆ
