## 🔁 รอบตรวจรายสัปดาห์ (ทุกวันศุกร์ ~15:00 · คำสั่ง user 05/11/2026)
1. `git fetch origin main` + `git checkout -B <branch> origin/main` + `npm install` → `node docs/wi/kit/wi_check.mjs origin/main` — ต่อเล่ม: ป้ายที่ "มีตอนทำคู่มือแต่หายตอนนี้" + commit ที่แตะหน้า/คอมโพเนนต์ของเล่ม
2. อ่าน diff ของ commit ที่เข้าข่าย แล้วตัดสินตามเกณฑ์ (user เลือก "ขั้นตอนเปลี่ยน"):
   - **ทำเล่มใหม่** เมื่อ: ปุ่ม/แท็บที่คู่มืออ้างถูกเปลี่ยนชื่อ-ย้าย-ลบ · มีหน้า/แท็บใหม่ในขอบเขตเล่ม · ลำดับขั้นทำงานเปลี่ยน · สิทธิ์/ผู้กดเปลี่ยน
   - **แค่สรุปรายงาน** เมื่อ: สี/ขนาด/ตัวเลข/ข้อความอธิบายเล็กน้อย · แก้บั๊กที่ไม่เปลี่ยนวิธีกด
3. เล่มที่ต้องทำใหม่: แก้ `content.py` / `spec.json` / `mock.patch` → `kit/make_book.sh <book> <OUT>` → render ภาพตัวอย่าง
   (`FONTCONFIG_FILE=docs/wi/kit/fonts.conf soffice -env:UserInstallation=file://<OUT>/lo --headless --convert-to pdf`)
   แล้ว**เปิดดูด้วยตาทุกหน้าที่แก้** (วงกลมชี้ถูกปุ่ม · ข้อความไม่ล้น · ภาษาไทยไม่เป็นช่อง) · ทุกป้ายที่อ้างต้อง `grep -rF` เจอใน `src/`
   · ตรวจ OOXML: unzip แล้ว `node audit/pptxvalid.mjs <dir>`
4. เลื่อน `base` ใน `books.json` ของ**ทุกเล่มที่ตรวจแล้วว่ายังตรง** (รวมเล่มที่ไม่ต้องทำใหม่) ไปที่ main ที่ตรวจ → commit + merge (เปลี่ยนแต่ docs = ไม่ deploy)
5. รายงาน user: เล่มไหนทำใหม่ (ส่งไฟล์) / เล่มไหนแค่สรุป / เอกสาร `docs/modules` ที่เจอว่าไม่ตรงโค้ด (**รายงาน ไม่แก้เอง** จนกว่า user เลือก)

## กับดักที่เจอแล้ว
- **vite หลายตัวพร้อมกันต้อง `cacheDir` แยก** ไม่งั้นได้ 504 "Outdated Optimize Dep" = จอว่าง/ธง crash ปลอม (`make_book.sh` แยกให้แล้ว) · ปิด vite ด้วย PID เท่านั้น ห้าม `pkill -f`
- **soffice หลายตัวพร้อมกันต้องแยก profile** (`-env:UserInstallation=…`) ไม่งั้นภาษาไทย/อีโมจิในภาพตัวอย่างเป็นช่อง □ — ตัว pptx ไม่ได้เสีย
- ภาษาไทยอยู่ช่อง complex-script ของ OOXML — `wi_build.py` ตั้ง `a:cs`/`a:ea` = Tahoma ให้ทุก run แล้ว ห้ามถอด
- mock คืนแถวซ้ำๆ ไม่สนตัวกรองฝั่ง server — การ์ดที่ต้องโชว์สถานะเฉพาะต้อง override ใน `mock.patch`
- `wi_check` นับป้ายที่**ไม่เคยอยู่ใน src** (ตัวเลขนับ · ข้อมูล mock) เป็น "ไม่เปลี่ยน" — ป้ายที่ฟ้องคือป้ายที่หายไปจริงระหว่าง base → main
- 🔴 **"ป้ายหาย 0" ≠ "เล่มยังตรง"** (รอบ 08/11) — เล่ม Planning & Store ฟ้อง 0 ป้าย ทั้งที่งานสโตร์ถูกยกเครื่องทั้งสาย
  (บอร์ดคัมบังเหลือดูอย่างเดียว · เลิกคิวเติม WIP · แท็บใหม่) เพราะป้ายเดิมยังมีอยู่ที่อื่นในโค้ด
  ⇒ **ต้องอ่าน subject + diff ของ commit ที่แตะเล่มทุกครั้ง** ตัวตรวจเป็นแค่ตัวชี้ ห้ามใช้ตัดสินแทน
- กวาด UI ทั้งระบบ (ตัด emoji บนปุ่ม/แท็บ · ปุ่มหัวเพจเกิน 2 เข้าเมนู ⋯) = **วิธีกดเปลี่ยน** สำหรับปุ่มที่ย้ายเข้า ⋯ —
  spec ใช้ `click` เปิดเมนูก่อนถ่าย ให้วงกลมชี้รายการในเมนูได้
