# 📘 Work Instruction Prompt Pack — ESM (Enterprise Shopfloor Management)

เอกสารนี้รวม **prompt สำเร็จรูป** สำหรับสร้าง Work Instruction (WI / คู่มือการใช้งาน) เพื่อสอน user แต่ละฟังก์ชันของระบบ ESM ของ Thai Summit Group

**วิธีใช้:** copy `MASTER PROMPT` ด้านล่าง 1 ครั้ง (วางกฎรูปแบบ) แล้วต่อด้วย prompt เฉพาะหน้าที่ต้องการ ป้อนเข้า AI (ChatGPT / Claude / Gemini) → ได้ WI ภาษาไทยพร้อมใช้ 1 หน้า/ฟังก์ชัน

> อัปเดตล่าสุด: จากการรีวิวโค้ดจริงทั้ง 23 หน้า (~30,000 บรรทัด) — ป้ายปุ่ม/ฟิลด์ในแต่ละ prompt ตรงกับ UI จริงในโค้ด

## 🧩 MASTER PROMPT (วาง 1 ครั้งก่อน prompt เฉพาะหน้า)

```
คุณคือผู้เชี่ยวชาญการเขียน Work Instruction (WI) สำหรับโรงงานอุตสาหกรรมยานยนต์ (Thai Summit Group)
ภารกิจ: เขียน "คู่มือการใช้งาน" ของฟังก์ชันในระบบ ESM (เว็บแอปบริหารโรงงาน) เพื่อสอนพนักงานหน้างานที่ไม่เชี่ยวชาญคอมพิวเตอร์

กลุ่มผู้อ่าน: Operator / Leader / Supervisor ในโรงงาน — ใช้ภาษาง่าย สั้น ตรง เป็นขั้นตอน

รูปแบบเอกสารที่ต้องออก (ภาษาไทยทั้งหมด):
1. หัวเอกสาร: ชื่อ WI, รหัสเอกสาร (เว้นให้กรอก), Revision, วันที่, ผู้จัดทำ/ตรวจสอบ/อนุมัติ (ตาราง)
2. วัตถุประสงค์ (Purpose) — 1–2 บรรทัด ทำหน้านี้ไปเพื่ออะไร
3. ขอบเขต & ผู้ใช้ (Scope) — ใครใช้ได้ (role) เห็น/ทำอะไรได้บ้าง
4. สิ่งที่ต้องเตรียมก่อน (Pre-condition) — ข้อมูล/สิทธิ์/หน้าอื่นที่ต้องตั้งค่าก่อน
5. ขั้นตอนการใช้งาน (Step-by-step) — เป็นข้อ 1,2,3... แต่ละข้อ:
   - บอกปุ่ม/เมนูที่ต้องกด (ใส่ชื่อปุ่มจริงในเครื่องหมาย " ")
   - บอกสิ่งที่จะเกิดขึ้นหลังกด
   - [ใส่รูปภาพ: ...] เป็น placeholder ให้แทรก screenshot
6. กรณีพิเศษ / เงื่อนไข (Rules & Validation) — สิ่งที่ระบบบังคับ, ห้ามทำ, ค่าที่ผิดแล้ว error
7. ปัญหาที่พบบ่อย & วิธีแก้ (Troubleshooting) — ตาราง อาการ → สาเหตุ → วิธีแก้
8. คำศัพท์/สัญลักษณ์ (Legend) — อธิบาย icon/สถานะ/ตัวย่อ

กติกา:
- ใช้ bullet และตารางให้อ่านง่าย หลีกเลี่ยงศัพท์เทคนิค (แปลเป็นภาษาชาวบ้าน)
- อ้างชื่อปุ่ม/แท็บ/ฟิลด์ ตามที่ระบุใน "ข้อมูลฟังก์ชัน" ด้านล่างเป๊ะ ๆ
- ทุกจุดที่ควรมีภาพให้ใส่ [ใส่รูปภาพ: อธิบายว่าเป็นภาพอะไร]
- เตือนกฎเวลา/กะให้ชัด (ก่อน 08:00 นับเป็นวันก่อนหน้า) เมื่อฟังก์ชันเกี่ยวกับวันที่งาน

ต่อไปนี้คือ "ข้อมูลฟังก์ชัน" ที่ให้เขียน WI:

# หมวด 2 · การผลิต

## 2.1 จัดการสายผลิต (Management — route `/management`)
```
ชื่อหน้า: จัดกำลังคน / จัดผังไลน์ (Man Management + 4M)
วัตถุประสงค์: บอร์ด "ใครยืนจุดไหน" ลากพนักงานที่มาทำงานวันนี้ไปวางที่สถานีบนผังไลน์ เห็นคะแนน skill fit ทันที บันทึกการเปลี่ยนแปลง 4M และดูไทม์ไลน์ผลิตของไลน์
ผู้ใช้:
- admin/manager/supervisor = จัดการได้ทุกไลน์
- leader = ล็อกเฉพาะไลน์ตัวเอง (dropdown ไลน์กดไม่ได้ เห็นเฉพาะคนในไลน์ตัวเอง)
- แสดงเฉพาะพนักงานที่ "มาทำงาน + PPE ครบ (หมวก/รองเท้า/ถุงมือ)" ของกะปัจจุบัน
ขั้นตอนหลัก (จัดคนเข้าสถานี):
1. เลือกไลน์จาก dropdown "ไลน์ผลิต" (ซ้ายบน) — ไลน์ย่อยรวมกันอัตโนมัติ
2. Pool "🔵 พร้อมทำงาน" = รายชื่อคนว่าง
3. Desktop: ลากการ์ดคนไปวางที่จุดบนผัง (hover เห็น fit score) | Mobile: แตะคน แล้วแตะสถานี | หรือคลิกสถานี → เลือกคนจากรายการเรียงตาม Fit
4. ระบบบันทึก + ถ้าย้ายข้ามจุดที่ไม่ใช่ตำแหน่งประจำ จะจัดประเภท Man-4M อัตโนมัติ:
   - Case 1 (ไลน์เดิม+สกิลผ่าน+เคยทำ) = เก็บ log อัตโนมัติ ไม่ต้องอนุมัติ
   - Case 2 (ข้ามไลน์+สกิลผ่าน) = ต้องแนบรูป OJT + SV อนุมัติ (ขึ้น ⚠️ ที่สถานี)
   - Case 3 (ข้ามไลน์+สกิลไม่ผ่าน/ไม่เคยทำ) = ต้องแนบรูป OJT + SV + QA อนุมัติ
5. คลิก ⚠️ ที่สถานี → modal "📎 แนบเอกสาร OJT" → อัปโหลด → "ส่งอนุมัติ"
ปุ่ม/งานอื่น:
- "📌 บันทึกตำแหน่งประจำ" (ใน station picker) = ตั้ง home position (กลับจุดนี้ไม่ต้อง log)
- "↩ Pool" = ส่งคนกลับ pool
- "🏷" หรือลากไป "🟡 งานนอกไลน์" = กำหนดงานนอกไลน์ (5ส/คัดงาน/แก้ปัญหาคุณภาพ/ปรับปรุงไลน์/อื่นๆ)
- บันทึก 4M เอง: ปุ่ม "⚙️ Machine" "📦 Material" "📋 Method" หรือ "+" ที่สถานี → 4M Modal (ต้องกรอกรายละเอียด, แนบรูปถ้าเป็น Change/ข้ามไลน์)
- toggle MAN/MACHINE/WIP ซ่อน-แสดงจุด, mini Heijunka board ดูอย่างเดียว
Pre-condition: ต้องมีรูปผังไลน์ + วางจุดสถานีที่หน้า "ตั้งค่าผังไลน์" ก่อน ไม่งั้นเห็นแค่ตัวเลขสรุป
Legend Fit: ผู้เชี่ยวชาญ≥100 / แก้ปัญหาได้≥75 / มาตรฐาน≥50 / ต้องดูแล≥25 / ยังไม่ผ่าน OJT
```

## 2.2 เช็คชื่อ & PPE (Checkin — route `/checkin`)
```
ชื่อหน้า: เช็คชื่อ & PPE + จองรถ OT
วัตถุประสงค์: เช็คชื่อพนักงานรายวันตามกะ ตรวจ PPE (หมวก/รองเท้า/ถุงมือ) บันทึกการลา และจอง OT/รถรับส่ง
ผู้ใช้: leader เห็นเฉพาะไลน์+ทีมตัวเอง (ซ่อนตัวกรอง Section/Line); role อื่นเห็นทุกคน กรองด้วย Section tabs + Line dropdown
กะอัตโนมัติ: 08:00–20:00=☀️กะเช้า, นอกนั้น=🌙กะดึก; ก่อน 08:00 workDate ถอยเป็นเมื่อวาน
ปุ่ม header: "🌙 Preview กะดึก" (จำลอง ปิดปุ่มบันทึก), "👁 เฉพาะกะนี้/👥 ทุกคน", "📄 ส่งออกฟอร์ม", "🚐 จองรถ OT", "💾 บันทึก"
คอลัมน์ตาราง: พนักงาน|กะ|มางาน(checkbox)|หมวก|รองเท้า|ถุงมือ|OT|🏖️การลา|หมายเหตุ|สถานะ|🚐จองรถ OT

- สถานะอัตโนมัติ: 🟢พร้อม/🟡PPEไม่ครบ/🔴ขาดงาน/🟣ลาเต็มวัน/🔵ลา
หลังกด "💾 บันทึก": บันทึก logs → บันทึกจอง OT → skill farming (+XP คนที่ทำจุดต้องใช้สกิล≥70%) → toast → ส่ง Telegram → อาจถาม "เปิดกะ Daily Report?"
Modal สำคัญ "🚐 จองรถ OT" (อิสระ): เลือกวันที่/กะ/ไลน์/ทีมได้อิสระ ไม่ต้องรอเช็คชื่อกะนั้น (เหมาะกรณีจันทร์แรกหลังสลับกะ) → ติ๊กคน + เลือกงานที่ทำ → "💾 บันทึกการจอง"
Modal "📄 ส่งออกฟอร์ม (PDF)": สร้าง PDF 2 หน้า (ใบ OT + บันทึกการมาทำงาน) เลือกเดือน/ครึ่งเดือน/ส่วนงาน
Pre-condition: ต้อง login; บันทึกไม่ได้ระหว่าง Preview กะดึก; ต้องมีตารางกะของวันนั้น (ไม่งั้นเตือนไปหน้า ตารางกะ)
```

## 2.3 Daily Report (บันทึกผลผลิตรายกะ — route `/daily-report`)
```
ชื่อหน้า: Daily Production Report — หน้าที่ซับซ้อนที่สุด บันทึกผลผลิต+Downtime แบบ real-time รายกะ คำนวณ OEE อัตโนมัติ
ผู้ใช้ & สิทธิ์:
- admin/manager/supervisor = เห็นแท็บ "⚙️ ตั้งค่า", อนุมัติปิดกะ, ปิดกะได้เลย, แก้/ลบได้เสมอ
- leader = เปิดกะ, สแกน order, บันทึกงานเสีย/Downtime, "ขอปิดกะ" (ต้องรอ SV อนุมัติ); แก้ได้เฉพาะกะที่ยัง open; เห็นเฉพาะไลน์ตัวเอง
- supervisor เห็นเฉพาะกะใน section ตัวเอง; admin ลบกะในประวัติได้
แท็บ: ⚡ Live กะนี้ | 📋 ประวัติ | 📤 Export | ⚙️ ตั้งค่า
ขั้นตอนหลัก (Live):
A. เปิดกะ: ปุ่ม "+ เปิดกะใหม่" → กรอกวันที่/ไลน์/กะ/เวลาเริ่ม → "เปิดกะ" (กันเปิดซ้ำ)
B. สแกนเปิด order: "📥 Scan เปิด Order" → สแกน PROD.NO (barcode บน Tag Card) → เลือก MAT.NO (Qty auto จาก Kanban Standard) → RH/LH จับคู่อัตโนมัติ → "📥 เปิด Order"
C. สแกนปิด: "📤 Scan ปิด/Confirm" → สแกน PROD.NO → Enter ยืนยัน = ปิดครบเป็น OK
D. บันทึกงานเสีย: "🔴 บันทึกงานเสีย" → เลือก MAT.NO + ประเภท → กรอก NG/สงสัย/ซ่อม
E. Downtime: "+ บันทึก Downtime" → เลือกโหมดเวลา (เริ่ม-จบ/เริ่ม+นาที/จบ+นาที) + ประเภท (นอกแผน/ในแผน) + เครื่องจักร + MAT.NO
F. รับยอดค้าง: banner "➡ มียอดค้างจากกะก่อน" → "📥 รับยอดต่อ"
G. ปิดกะ: "📋 ขอปิดกะ"(leader)/"🔒 ปิดกะ"(SV+) → ยืนยันเวลาเริ่ม/ปิดจริง → ตัดสินใจ order ที่ยัง open (✅ผลิตครบ/➡ยกยอดต่อ/✕ยกเลิก) → ดู OEE Preview → ยืนยัน
H. SV อนุมัติปิดกะ (pending_close): "🔍 ตรวจสอบ & อนุมัติ" → "✅ ยืนยันอนุมัติ" (ปิด+ตัด stock ตาม BOM) หรือ "✕ ปฏิเสธ"

C. 3 แท็บวางหมุด:
   - 📍 จุดงาน: คลิกที่ว่างบนรูป → กรอกชื่อจุด + ติ๊กสกิลที่ต้องการ+คะแนนขั้นต่ำ% + 💰 ค่าฝีมือ
   - 📦 จุด WIP: 🧱Material(เรียกจากสโตร์)/📦Packaging; mat no./ภาชนะ + Min/Max/ปัจจุบัน; "🔔 เรียกเติม" เมื่อต่ำกว่า min
   - ⚙️ เครื่องจักร: เลือกเครื่องจากทะเบียน + redundancy group; "🔗 เชื่อมต่อ" เส้นทางการผลิต
D. ล่างแถบขวา: 👥 Standard Manpower (กะเช้า/ดึก คน + cost center + หัวหน้า); ✍️ ผู้อนุมัติประจำส่วนงาน
gotcha: ต้องมีไลน์+รูปก่อนวางจุด; ต้องคลิกในพื้นที่รูปจริง(มี letterbox)+ห่างจุดอื่น; ลาก>3px=ย้าย; พิกัดเก็บเป็น % ของรูปจริง; เครื่องจักรทะเบียนอยู่ที่ Machine Database
