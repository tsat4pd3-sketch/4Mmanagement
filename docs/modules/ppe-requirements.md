## 🔴 กฎที่ห้ามพัง

1. **การตกทอดตัดสินที่ `src/utils/ppeRequirements.js` ที่เดียว** (`resolvePpe`) ห้ามคิดลำดับชั้นเองในหน้า
   · ชั้น: `plant → section → line (ไล่สายแม่→ลูกด้วย `lineChainIds`) → station` · **ชั้นล่างชนะชั้นบน**
2. **"ไม่ได้ตั้ง" ≠ "ตั้งว่าไม่ต้อง"** — ไม่มีแถว = ตกทอด · `required=false` = **ยกเว้น**
   ยุบ 2 อย่างนี้เป็นติ๊ก/ไม่ติ๊ก = ยกเว้นรายไลน์ไม่ได้เลย ต้องไปแก้ชั้นบนซึ่งกระทบคนอื่น
3. **ทุกชิ้นต้องตอบได้ว่ามาจากชั้นไหน** (`sourceOf` + `ppeSourceText`) — จอตั้งค่าต้องเขียนให้เห็น
   ไม่งั้นคนตั้งค่าไม่รู้ว่าที่เห็นเป็นของหน่วยตัวเองหรือตกทอดมา แล้วไปแก้ผิดชั้น
4. 🔴 **อ่านทะเบียนไม่ได้ = `unknown` ห้ามบีบเป็น "ไม่ต้องใส่อะไรเลย"** — จอต้องเขียนบอก
5. 🔴 **`ppeStatusOf` แยก `none` (ยังไม่ได้ตรวจ) ออกจาก `missing` (ตรวจแล้วขาด)** — ยุบกัน = คนที่ยังไม่มีใครตรวจ
   ถูกรายงานว่า "ไม่ใส่ PPE"
6. **ค่าพื้นฐานทั้งโรงงาน = 3 ชิ้นเดิม** (seed ไว้ที่ชั้น `plant` ตอน migration)
   ไม่ seed = วันแรกที่ deploy ทั้งโรงงานกลายเป็น "ไม่ต้องใส่อะไรเลย" = ถอยหลังแบบเงียบๆ
7. **ซิงก์กลับคอลัมน์เดิมเสมอ** (`legacyPatchOf` → `savePpeChecks`) — จอเช็คชื่อ/ชิป "PPE ไม่ครบ"/
   `getRowStatus` ยังอ่าน 3 คอลัมน์นั้น · ไม่ซิงก์ = จอเก่ากับจอใหม่เถียงกันว่าใครใส่ครบ
   · ซิงก์ล้ม = **ต้องบอกบนจอ** (`legacySynced:false`) ห้ามกลืน
