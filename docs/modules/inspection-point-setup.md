## ตอนนี้ — ชิ้นส่วนกลางชุดเดียว (`src/components/inspect/` + `SpinAnnotator`)

| ชิ้น | หน้าที่ |
|---|---|
| `InspectEditorModal` | กรอบโมดัล: หัว · body เลื่อนได้ · ยกเลิก/บันทึก (**แก้ทั้งชุดแล้วกดบันทึกครั้งเดียว**) |
| `PinWorkspace` | ผัง "รูปซ้าย sticky · การ์ดขวา" (จอแคบ = รูปตรึงบนหัว) + หัวรายการ + `+ เพิ่มจุดตรวจ` + แถบไปที่จุด |
| `SpinAnnotator` | ตัวปักหมุด: รูปหลายภาพ · **ซูม 100–400%** · หมุดผูกกับรูปที่วาง · ลากป้ายเลขหลบ · `spinnable` (PM ลากหมุนรอบเครื่อง / QA แผ่นแบบตั้งชื่อ) · PDF (ดูได้ ปักไม่ได้) · ตั้งชื่อ/เปลี่ยนรูปแผ่น (หมุดอยู่ที่เดิม) |
| `PointCardShell` | เปลือกการ์ด: เลขจุด · 🔘 วางตำแหน่ง / ✕ ถอดหมุด · × ลบ · 📷 รูปโคลสอัพ (ผ่าน `acceptImageFile`) |
| `PointJumpBar` + `usePointJump` | ชิปทุกจุด + ค้นเลข/ชื่อ (`cpJumpMatches`) · เลื่อนเฉพาะ body โมดัล + เรืองกรอบ 2.5 วิ · หมุนรูปไปเฟรมของหมุด |
| `useWideModal` | เกณฑ์จอกว้าง 1180px ตัวเดียว |

**วิธีใช้ที่เหมือนกันทั้ง 2 ระบบ (สอนครั้งเดียว):**
1. เปิดโมดัล (PM: แถวอุปกรณ์ · QA: ปุ่ม 🎯 ตั้งค่าจุดตรวจ & Drawing / ✏️ ในตาราง / แตะหมุดบนหน้า)
2. เพิ่มรูป (+) — PM ผ่านหน้าครอป 4:3 · QA ไม่ครอป (drawing ต้องอ่าน dimension · บีบ 2560px) ตั้งชื่อแผ่นจาก view มาตรฐาน
3. `+ เพิ่มจุดตรวจ` → การ์ดใหม่ท้ายลิสต์ (เลื่อนไปให้เอง) → 🔘 วางตำแหน่ง → แตะบนรูป (ซูมได้)
4. กรอกสเปคในการ์ด · แนบ 📷 รูปจุด (หมุดขึ้น 🔍)
5. แตะหมุด = ไปที่การ์ดจุดนั้น · กดบันทึก

**ที่ต่างกันโดยตั้งใจ = เนื้อในการ์ดเท่านั้น**
- PM `CheckpointCard` (`PMSetup.jsx`): กลุ่ม Item (เลข `1.3` อัตโนมัติ) · หมวด · วิธีตรวจ · Variable/ค่าวัด/OK-NG/Note · LCL/UCL · ⧉ อีกแกน
- QA `QaPointCard` (`QaPointsEditor.jsx`): เลข balloon ตามแบบ (พิมพ์เอง · ตั้งต้น = ถัดจากตัวล่าสุด `nextBalloonOf`) · Variable/Attribute · LSL/Nominal/USL (พรีวิว `specLabel`) · Rank M/SC (= สีหมุด) · Stage · ความถี่/n · ใช้งาน
- PM มีเครื่องมือคัดลอกไปเครื่องอื่น/ย้ายแผนก (QA ยังไม่มี — ยังไม่มีคำขอ)

## 🔴 กฎ

- **จอตั้งค่าจุดตรวจระบบใหม่ (หรือแก้ของเดิม) ต้องประกอบจากชิ้นส่วนกลางชุดนี้** ห้ามวาดโมดัล/ผังรูป-การ์ด/หัวการ์ด/แถบไปที่จุดเอง
  — แก้พฤติกรรมที่ชิ้นกลาง = มีผลทั้ง PM + QA พร้อมกัน (นั่นคือจุดประสงค์)
- พิกัดหมุดในโมดัลเป็น 0..1 ทั้งคู่ · **QA เก็บลงฐาน 0–100** (`qa_inspection_items.pos_x/pos_y` — จอตรวจ `QaCheckSheet` อ่านแบบนี้) แปลงตอนโหลด/บันทึกใน `QaPointsEditor` ที่เดียว
- QA จุดเก่าที่ `drawing_id` ว่าง = อยู่แผ่นแรก (พฤติกรรมเดิม)
- บันทึก QA ลำดับตายตัว: แผ่นรูป (ต้องได้ id) → จุดตรวจ → ลบจุดที่เอาออก → ลบแผ่นที่เอาออก → เก็บกวาดไฟล์
  · UPDATE/DELETE ผ่าน `checkWriteRows` · **ลบไฟล์ใน storage หลังแถวในฐานเลิกอ้างแล้วเท่านั้น**
  · ล้มกลางทาง = เขียนบนจอ + เก็บ id ของแถวที่เพิ่งเกิดไว้ใน state (กดบันทึกซ้ำ = update ไม่ insert ซ้ำ)
- ลบจุดตรวจ QA ได้ — ผลตรวจเก่าอ่านจาก snapshot ในแถวผล (`qa_inspection_results.item_id` = on delete set null)
- QA ไม่มี Undo/Redo แล้ว (ถอด `useUndoHistory` ออกจากหน้า) — โมดัลคือ "ร่าง" กดยกเลิก = ทิ้งที่แก้ เหมือน PM
