# 📈 SPC อุปกรณ์ — ค่าตัวเลขจากใบตรวจ AM/PM + ค่าชิม (2026-11-26 · คำสั่ง user)

> *"ทำ spc พวก shim record หรือเอาข้อมูลการตรวจ ทั้ง am,pm ที่เป็นการลงค่าตัวเลขมาสร้างกราฟเพื่อควบคุมกระบวนการ"*

## สิ่งที่ user เลือก (26/11)
- ที่อยู่ = **แท็บ "SPC อุปกรณ์" ใน PM hub** (`/pm?tab=spc` · piggyback `page:/pm-check`) **+ ปุ่ม 📈 ที่ข้อตัวเลขในใบตรวจ** (เปิดหน้าต่างในที่เดิม — AM ที่ไม่มีสิทธิ์ PM hub ก็ดูได้)
- ข้อที่ขึ้น = **ทุกข้อตัวเลข (variable/measure) อัตโนมัติ + ปิดรายข้อได้** — `jig_checkpoints.spc_enabled` (DR · migration `20261126d` · **apply แล้ว** · default true) · PM Setup มีช่องติ๊ก "ขึ้นกราฟ SPC" (ปิดข้อที่เป็นตัวนับ เช่น รอบการเปลี่ยนไกด์พิน)
- เส้นควบคุม = **คิดจากข้อมูล** (ย้อนหลัง 180 วัน) · **ครบ 20 จุดจึงตัดสิน** (`SPC_MIN_POINTS`) — ต่ำกว่านั้น = "เส้นควบคุมชั่วคราว n/20" ไม่ทาสีจุดหลุด ไม่โชว์ Cpk เป็นค่าตัดสิน
- หลุดการควบคุม = **แสดงบนจอ** (จุดแดง + รายการ) · ยังไม่ส่งแจ้งเตือน

## กติกา
- variable = ค่า ①②③ ที่กรอก (subgroup = จำนวนที่พบบ่อยสุด · แถวที่จำนวนไม่ตรงถูกตัดและเขียนบอก "ตัดออก N ครั้ง") · measure = ค่าเดียว (I-MR)
- ค่าชิม = `fixture_shim_events.shim_after_mm` เรียงตาม `event_at` · เพดานชิม (`max_shim_mm`) = USL · (26/11 ยังไม่มีประวัติชิมเลยสักแถว — แท็บเขียนว่ายังไม่มีข้อมูล)
- แกน Y ต้องครอบเส้นควบคุม + spec (domain 'auto' ตัดเส้นนอกช่วงข้อมูลทิ้ง) · ทศนิยมแกนตามช่วงข้อมูล
- อ่านไม่ได้ = เขียนบอกบนจอ ห้ามโชว์กราฟว่างเหมือนปกติ

## ข้อมูลจริง ณ 26/11
ค่าตัวเลขยังน้อย — มากสุด ~15 จุด/ข้อ (แรงดันลม SP-54 · Inlet Air Pressure AB-02) ⇒ ทุกข้อยัง "ชั่วคราว" · ค่าชิม 0 แถว
