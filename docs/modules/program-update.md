## 🔴 กฎที่ห้ามพลาด

1. **แหล่งความจริงคือ git ไม่ใช่ไฟล์ที่คนพิมพ์มือ**
   ทะเบียนอัพเดทที่ต้องมีคนมาจดเองจะล้าสมัยตั้งแต่สัปดาห์ที่สอง (บทเรียนซ้ำในโปรเจคนี้: ช่องที่ไม่มีใครกรอก = ช่องตาย)
   · commit มีอยู่แล้วทุกครั้งที่แก้ของ ⇒ อ่านจากนั้น
2. **หน้านี้ไม่แตะ Supabase เลย** — ไม่มี egress · ไม่มีสิทธิ์เขียน · `fetch` ไฟล์ static ของตัวเอง
3. **ต้องโชว์ `generatedAt` บนจอ** — ไฟล์เก่าค้างต้องเห็นเอง (ห้ามเนียนว่าสด)
4. **โหลดไม่ได้ = เขียนว่าโหลดไม่ได้** ห้ามขึ้น "ไม่มีอัพเดท" (0 คนละความหมายกับล้มเหลว · กฎความซื่อสัตย์ของจอ)
5. 🔴 **ชนิดต้องมีตะกร้ารับท้ายลิสต์** (`other`) — commit ที่ไม่ได้เขียนตามรูป conventional
   (วัดจริง 01/10: 1,153 รายการ มี ~200 ที่ไม่มี prefix) **ห้ามหายจากจอ**
   กฎเดียวกับไลน์ที่ `line_type` ว่างต้องไม่หลุดจาก dropdown
6. **เอาแค่บรรทัดหัวเรื่องของ commit** ไม่เอา body ⇒ trailer (ผู้ร่วมเขียน/ลิงก์ session) ไม่มีทางหลุดออกจอ

## กับดักที่กัน (เขียนไว้ในสคริปต์)

- 🔴 **shallow clone ต้องไม่ล้างประวัติ** — Render อาจ clone ตื้น (`git log` ได้ไม่กี่ commit)
  ถ้าของใหม่น้อยกว่าของเดิม > 10% = **ไม่เขียนทับ** + เตือน (ไม่งั้นหน้าจะเหลือบรรทัดเดียวเงียบๆ)
- **ห้ามทำให้ build ล่ม** — git ใช้ไม่ได้/พังกลางทาง = เตือนแล้ว `exit 0` คงไฟล์เดิมไว้
- **เพดาน 1,500 รายการ** — เกินแล้วตัด + ติดธง `truncated` ให้จอเขียนบอก (ยังไม่ถึง)
