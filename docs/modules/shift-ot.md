### OT วันหยุด (2026-07-10)

ตาราง OT ด้านบนใช้เฉพาะ**วันทำงานปกติ** — วันหยุด (`company_calendar.day_type != 'working'`) การมาทำ OT คือมาทั้งกะ มี 4 รูปแบบ:

| รูปแบบ | เวลา | ค่าใน `ot_night_bookings.ot_period` |
|---|---|---|
| เช้า 8 ชม. | 08:00–17:00 | `holiday_day_8h` |
| เช้า 10 ชม. | 08:00–20:00 | `holiday_day_10h` |
| ดึก 10 ชม. | 20:00–08:00 | `holiday_night_10h` |
| ดึก 8 ชม. | 22:00–08:00 | `holiday_night_8h` |

- source of truth เดียว: `src/utils/otPeriods.js` (label/ตัวเลือกตามกะ/ค่า default) — ห้าม hardcode ช่วงเวลาซ้ำในหน้า
- `ot_period = null` = OT ต่อท้ายกะวันทำงานปกติ (และการจองเก่าก่อนมีฟีเจอร์นี้ — Report แสดง "⚠️ ไม่ระบุ" เมื่อวันนั้นเป็นวันหยุด)
- จุดจองทุกทางในหน้าเช็คชื่อ (กะดึกจองพรุ่งนี้ / has_ot กะเช้า / ช่องวันหยุดล่วงหน้า 🔶 / modal จองรถ OT อิสระ) จะโชว์ select ช่วงเวลาอัตโนมัติเมื่อวันที่จองเป็นวันหยุด — default 8 ชม. ของกะนั้น
- migration: `20260710_ot_booking_holiday_period.sql` (Main project)

**วันหยุดจ่าย 75% — มาตรา 75 (2026-07-21):** `company_calendar.day_type = 'shutdown75'` (สีม่วง ตั้งจากปฏิทินบริษัท — เพิ่มรายวัน ไม่มีใน bulk รายสัปดาห์) = หยุดชั่วคราวเหตุลูกค้าลด order: หยุดได้ค่าจ้าง 75% · ถูกเรียกมาทำงาน = ค่าแรงปกติ · **ระบบเก็บเป็นข้อมูลอ้างอิง ยังไม่คำนวณเงิน** · ความหมาย "วันหยุด" แยก 2 ชั้น: (ก) วันหยุดโรงงาน (working-day calc: kanban/LPA/แผนงาน — เช็ค `!= 'working'`) shutdown75 นับเป็นหยุด (ข) **วันหยุดแบบ OT** (จองรถ OT/ชม. OT 8-10 ชม.) ใช้ helper `isOtHolidayType()`/`isOtHoliday()` ใน `companyCalendar.js` = **ot15/ot2 เท่านั้น** — โค้ดใหม่ที่เช็ควันหยุดต้องเลือก helper ให้ตรงความหมาย ห้ามเช็ค `!= 'working'` แบบเหมา · migration `20260721_calendar_shutdown75.sql`

## 🏖️ เวลาพักของ "วันที่ไม่ใช่วันทำงาน" (2026-10-27 · คำสั่ง user)

**กฎหน้างาน:** *"เวลาพักวันหยุด OT ไปอิงกับปฏิทิน — วันไหนไม่ใช่วันทำงาน หยุด 50 จะกลายเป็น 60"*

**ค่าอยู่ในทะเบียน ไม่ได้อยู่ในโค้ด** — `break_policies.duration_min_holiday`
(migration `20261027_break_policy_holiday_min.sql` · **apply แล้ว** ฝั่ง DR)
ตั้งที่ **Daily Report → ⚙️ ตั้งค่า → ☕ นโยบายหยุดพัก → ช่อง "วันหยุด (นาที)"**
🔴 **ห้ามฝังเลข 50/60 ในโค้ด** — วันหลังโรงงานเปลี่ยนเป็น 45/70 ต้องแก้ได้เองโดยไม่ต้องรอโปรแกรมเมอร์

### "วันไหนคือวันทำงาน" — กฎชุดเดียว `isWorkingDayFrom()` (`src/utils/workingDay.js`)

| วันนั้นในปฏิทิน | ผล |
|---|---|
| มาร์ค `working` | วันทำงาน |
| มาร์ค `ot15` · `ot2` · `shutdown75` | **ไม่ใช่วันทำงาน** |
| ไม่ได้มาร์ค · จันทร์–ศุกร์ | วันทำงาน |
| ไม่ได้มาร์ค · เสาร์–อาทิตย์ | **ไม่ใช่วันทำงาน** |

🔴 **ปฏิทินยังไม่โหลด = `null` (ไม่รู้) ⇒ ใช้นาทีปกติ = พฤติกรรมเดิมเป๊ะ** ห้ามเดาว่าเป็นวันหยุด
(เดาผิด = หักเวลาพักเกิน = %A/%P ตกทั้งกะโดยไม่มีใครเห็น)
· `countWorkingDaysInMonth()` ใน `companyCalendar.js` เรียกฟังก์ชันเดียวกันนี้ —
**ห้ามเขียนกฎชุดที่ 2** ไม่งั้นตัวนับวันทำงานกับการหักพักจะไม่ตรงกัน

### ลำดับการทับนาทีพัก (สำคัญ)

```
ค่ากลางของนโยบาย (duration_min)
  → วันหยุด (duration_min_holiday)        ← applyHolidayBreaks()  utils/workingDay.js
    → ข้อยกเว้นรายไลน์ (break_line_rules)  ← applyBreakLineRules() utils/breakLineRules.js
```
🔴 **ไลน์ที่ตั้งนาทีของตัวเองไว้ ชนะเสมอ** (เป็นค่าที่เจาะจงที่สุด) —
ถ้าสลับลำดับ ไลน์ที่ตั้งเอง 10 นาทีจะถูกวันหยุดทับกลับเป็น 60 เงียบๆ

· ติดป้าย `holiday_min` / `holiday_central_min` มากับ policy ให้จอเขียนได้ว่า "วันหยุด 60 จากปกติ 50"
  (แพทเทิร์นเดียวกับ `line_rule_min`)
· เว้นว่าง (`null`) = ใช้ `duration_min` ทุกวันเหมือนเดิม · **`0` = วันหยุดไม่พักเลย** (คนละความหมายกับเว้นว่าง)
· ด่าน `holiday-break-single-entry` (`regressionGuards`) + เทส `workingDay.test.mjs` 11 เคส

⚠️ **ยังไม่ได้ตั้งค่าจริง** — ต้องให้ user ใส่ `60` ที่นโยบายพักเที่ยง (ตอนนี้ยัง `null` = เท่าเดิมทุกวัน)
