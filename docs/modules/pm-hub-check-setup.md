### กฎ (เจ้าของกฎ = `src/utils/ngReason.js` · ห้ามเขียนเงื่อนไขซ้ำในหน้า)

| ฟังก์ชัน | ตอบคำถาม |
|---|---|
| `ngReasonCheck({ attr, text, carry, accepted })` | เหตุผลพอให้บันทึกไหม (`ok` + `blockText`) |
| `carryNgReason({ prev, mo, machine })` | ของเก่า "ยกมาได้ไหม" — `null` = ต้องพิมพ์เอง |
| `okWhileMoOpen({ attr, mo, machine })` | ติ๊ก OK ทั้งที่ใบซ่อมยังค้าง = ข้อความเตือน |
| `moUnresolved(mo)` | ใบซ่อมยังไม่จบงาน (เปิดอยู่ + ยังไม่ `repair_done_at`) |

- 🔴 **เช็คตอนกดบันทึกจริงใน `handleSave` ไม่ใช่แค่ซ่อนปุ่ม** — ช่องเหตุผลเป็นของรายจุด คนเลื่อนข้ามได้
  (ด่าน `ng-needs-reason` ตรวจทั้ง "เรียก `ngReasonCheck()` ก่อน `setSaving(true)`" และ "ผลต้องนำไป `return`")
- 🔴 **จุดที่เป็นค่าวัด (`variable`/`measure`) ไม่ต้องมีเหตุผล** — ตัวเลขที่อ่านได้คือคำอธิบายอยู่แล้ว
  และ NG ของมันคำนวณจากเกณฑ์ ไม่ใช่คนกด ⇒ ไม่มีเคส "กดผิด"
- 🔴 **ยกของเก่ามาแล้วต้องให้คนกดปุ่ม "ใช้เหตุผลเดิม"** — เติมให้เงียบๆ = คนกดผิดได้เหตุผลติดมาเอง
  ดูเหมือนตั้งใจ ซึ่ง**แย่กว่าไม่มีเหตุผล** · กดแล้วข้อความเดิมถูกเขียนลง `action_text` จริง ไม่ใช่อ้างว่ายกมา
- 🔴 **เงื่อนไขที่ "ยังยกได้"** มี 2 ทาง · ตัดสินจาก **ทะเบียนเครื่อง** ก่อน **ใบซ่อม**:
  1. `machines.usability = 'temp'` (ช่างประกาศ *แก้ไขเบื้องต้นแล้ว รอของมาเปลี่ยน*) → ยกได้เสมอ
  2. ใบซ่อมของจุดนั้นยังไม่จบ (`moUnresolved`) → ยกได้
  · **`usability = 'ok'` = หยุดยกทันที** (ช่างประกาศว่าใช้ได้แล้ว) ไม่งั้นเหตุผลเก่าติดไปทุกรอบตลอดกาล
- 🔴 **ยกเฉพาะ "จุดตรวจเดิม"** — `src/lib/ngHistory.js` คืน `byCp[checkpoint_id]` รายจุด

  (ผูก MO↔ใบตรวจผ่าน `mtn_orders.source_inspection_id` — ระดับใบ ไม่มีระดับจุด ⇒ ใบตรวจเดียวกัน

  ห้ามกลืนเป็น "ไม่เคย NG" (กลืน = คนต้องพิมพ์เองทั้งที่ควรยกได้ รำคาญแต่ไม่อันตราย — แต่จอต้องบอก)

### กฎหลังแก้ (ทุก session ที่แตะจอนี้ต้องรู้)

- 🔴 **การปักหมุดจำเป็นแค่กับ "แตะหมุดบนรูปเพื่อเลือกข้อ"** — ไม่ใช่กับเลขข้อ ไม่ใช่กับตัวโหมดทีละข้อ
  · ปักไม่ครบ = ยังใช้โหมดทีละข้อได้ (เลือกข้อด้วยชิปเลข / ข้อก่อน-ข้อถัดไป) แค่แตะหมุดไม่ได้ — **จอต้องเขียนบอกว่าปักแล้วกี่/กี่** ห้ามบล็อกเงียบ
  · ป้ายปุ่ม: ปักครบ = `เฉพาะจุดที่แตะ` ↔ `ทุกข้อ` · ปักไม่ครบ = `ทีละข้อ` ↔ `ทุกข้อ`
- 🔴 **เลขข้อขึ้นเสมอ** ทุกชนิดแถว (`AttrRow` · `MeasureRow` · `VariableRow`)
- 🔴 **รูปของจุดตรวจขึ้นจอใหญ่ได้ แต่ห้ามวาดหมุดทับ** — พิกัดหมุดเป็น % ของ **รูปเครื่อง** (ผูก `image_id`)
  คนละรูปกับ `checkpoints.image_path` ⇒ วาดทับ = หมุดชี้ผิดจุด (กฎ §5.1 `docs/UI-CONVENTIONS.md`)

    (ไม่งั้นรูปใหญ่ไม่เกี่ยวกับข้อที่กำลังตรวจ) · มีปุ่มสลับ 2 ทางเสมอ + ป้ายบอกว่ากำลังดูรูปอะไร

ของคิวรีถัดไป ต้องกรองค่าว่างซ้ำฝั่ง client เสมอ (คลาสเดียวกับ `[...a, ...b]` ใน `src/utils/mergeRows.js`)
