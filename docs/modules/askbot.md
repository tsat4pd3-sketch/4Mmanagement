## 🔴 กฎของโมดูล

1. **ไม่เข้าใจ = ไม่เดา** — เจตนาไม่รู้จัก → เสนอรูปแบบที่ถามได้ · ชื่อตรงหลายตัว (ไลน์ชนพาร์ท / `hdf` → HDF1, HDF2) → ปุ่มให้เลือก
2. **ห้ามมีสูตรชุดที่ 2** — ทุกตัวเลขผ่านสูตรกลางที่จออื่นใช้ (ตารางข้างบน) · เพิ่มเครื่องมือใหม่ต้องหา "จอที่ตอบคำถามนี้อยู่แล้ว" แล้วใช้ของกลางชุดเดียวกัน
3. **OEE/downtime/ของเสีย นับเฉพาะกะที่ปิดแล้ว** (`status = 'closed'`) — กะเปิด/รออนุมัติปิดต้อง **เขียนว่ายังไม่นับกี่กะ** · void ไม่นับ
   · 🟢 **ยอดผลิต = ยอดสะสม ⇒ รวมกะที่กำลังเดินด้วย** (20/11 · user ทัก "daily report มียอดเพิ่มเรื่อยๆ แต่แชทตอบ 0") + เขียน "รวมกะที่กำลังเดิน N กะ — ยอดยังเพิ่มได้"
   · พาร์ทหลาย MAT: โชว์เฉพาะ MAT ที่มียอด · ที่ไม่มีบอกเป็นจำนวน
4. **ขอบเขต = `lineScope()`** ตัวเดียวกับทุกจอ (รันในเบราว์เซอร์ผู้ถาม) — ไลน์นอกขอบเขต = บอกตรงๆ · ตัดแถวทิ้ง = บอกจำนวน · `unsure` = เขียนเตือน
5. **อ่านไม่ได้ ≠ ไม่มีข้อมูล** — ทุกคิวรีล้ม/ชนเพดาน (`truncated`) ต้องตอบว่าอ่านไม่ได้ ห้ามตอบ 0
6. **ยอดผลิตเป็น "ชิ้น"** — ไม่ยุบคู่ RH/LH (กฎ "ชิ้น ≠ shot") · ยุบเฉพาะชั้น OP
6.1 **เลข 0 นำหน้าไม่นับตอนค้นชื่อ** — "060" เจอ "Line 60" (20/11 · เดิมหาไม่เจอแล้วตกไปที่พาร์ท 16E060 เงียบๆ) · ไลน์ชนเลขพาร์ท = ปุ่มให้เลือก
6.2 **ปุ่มลัดใต้กล่อง = `HINT_CHIPS` 3 ปุ่ม** (user 20/11 "รกเกินไป") · รายการเต็ม `ASK_HINTS` โชว์เฉพาะตอนตอบว่าไม่เข้าใจ
7. **ตัวย่อเดือนต้องมีจุด** (`ม.ค.`) — แบบไม่มีจุด (`มค`) เป็นข้อความย่อยของคำทั่วไปได้ ("ซ่อมค้าง" มีตัวอักษร ม-ค ติดกัน) · เจอจริงตอนลองถาม
8. **ขอบเขตกรอง 2 ชั้น** — ตัวกรองคิวรี + กรองซ้ำฝั่งเบราว์เซอร์ใน `closedAndOpen()` (ห้ามพึ่งชั้นเดียว)
9. **ชื่อเลขต้องตรงทั้งตัว** — `ชุดที่ 1` ห้ามได้ 10–15 · `060` ห้ามได้ `0601` · **ตัดคำไทยห้ามตัดกลางพยางค์** (`ที` ใน `ชุดที่`)
10. **คอลัมน์ downtime ชุดเดียว `DT_COLS`** — มี `started_at/ended_at` (ตัดพัก) + `planned_cap_min` (เพดาน · มีด่าน)
