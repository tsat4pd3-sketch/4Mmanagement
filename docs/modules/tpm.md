## กฎ (ห้ามหลุด)

1. **เจ้าของกฎ = `src/utils/tpm.js` ที่เดียว** — `critGrade` · `critThresholds` · `ftagState` · `ftagActions` · `whyWhyMissing` · `closeGate`
   จอ `/tpm` และใบ MO เรียกจากที่นี่ **ห้ามคิดเกรด/สถานะแท็กเองในหน้า** (เทส `utils/__tests__/tpm.test.mjs`)
2. **ข้อมูลไม่ครบ = ไม่มีเกรด ห้ามเดา** — ให้คะแนนไม่ครบ/ยังไม่ประเมิน/อ่านเกณฑ์ไม่ได้ ⇒ `grade:null` + `reason` · จอเขียนเหตุผลด้วย `critReasonText()`
   · ประเมินไม่ครบ **≠ เกรด C**
3. **% ตัดเกรด** = คะแนนถ่วงน้ำหนัก ÷ คะแนนเต็ม (ทุกข้อ 1 = 33% · ทุกข้อ 3 = 100%) · ค่าเริ่ม A ≥ 70 · B ≥ 45 (`tpm_settings` แก้ที่แท็บ "เกณฑ์")
   · หัวข้อที่ติ๊ก `force_a` (ค่าเริ่ม = ความปลอดภัย) ได้ 3 = **A ทันที** ไม่ว่าคะแนนรวม
4. **จับคู่เลขเครื่องในใบ MO กับทะเบียน** ผ่าน `resolveEquip()` (mtnMetrics) เท่านั้น — `gradeForMachineNo()` / `useTpmGrade()`
5. **ด่าน Why-Why (`closeGate`)**: เกรด A + จังหวะปิดใบ (`close` / `cost_mgr_close`) + ไม่ใช่โหมดแก้ย้อนหลัง ⇒ ต้องมี
   อาการเสีย · ทำไม ≥ `WHY_MIN` (3) ชั้น · การป้องกันเกิดซ้ำ (+ รายละเอียด / เหตุผลถ้าเลือก "ไม่ต้องทำ")
   🔴 **ไม่รู้เกรด (เครื่องไม่อยู่ในทะเบียน/ยังไม่ประเมิน/อ่านไม่ได้) = ไม่บังคับ** แต่ช่องบอกเหตุผล — บังคับทั้งที่ไม่รู้ = ใบซ่อมทั้งโรงงานปิดไม่ได้
   · ระหว่างกำลังอ่านเกรด = ห้ามกดปิด (บอกให้รอ) · ช่องอยู่ทั้งขั้นลงผลซ่อมและขั้นปิดใบ (ผู้ปิดเติมได้ถ้าช่างยังไม่กรอก)
6. **F-Tag**: แดง = ต้องใช้ช่าง (ปิดเองไม่ได้ ต้องผ่าน MO หรือเปลี่ยนสี) · ขาว = ผู้ปฏิบัติงานแก้เองแล้วปิดพร้อมวิธีแก้
   · ปิด/ยกเลิก **ต้องมีข้อความ ≥ 5 ตัวอักษร** (CHECK ฝั่ง DB + `noteOk()`) · **ไม่มีการลบ** (ไม่ GRANT delete)
   · ใบซ่อมที่ผูกถูกยกเลิก/ตีกลับ (`cancelled`/`rejected`) ⇒ แท็กกลับมาค้าง (`mo_dropped`) ให้คนเปิดใบใหม่หรือปิดพร้อมเหตุผล
   · เปลี่ยนสถานะแบบ compare-and-swap (`.eq('status', เดิม)`) + `checkWriteRows`
7. **เลขแท็ก `FT-YYMM-0001`** ออกโดย trigger `fn_tpm_ftag_no()` = สูงสุดของเดือน(เวลาไทย)+1 + advisory lock (กฎ "ห้าม count()+1")
8. **สิทธิ์ 3 ชั้น**: `page:/tpm` · `tpm:ftag` (ติด/ปิด/ยกเลิก) · `tpm:assess` (ประเมิน + แก้เกณฑ์) · ชั้น ③ `canWriteLine(ไลน์ของแท็ก/เครื่อง)`
   · **ติดแท็กข้ามไลน์ได้** (เจอที่ไหนแจ้งได้ เหมือนแจ้งซ่อม) · ปิด/ยกเลิก/ประเมิน = ไลน์ในขอบเขตตัวเอง
   · แปลงเป็น MO ต้องมี `mtn_repair:report` ด้วย · payload แบบเดียวกับ "เปิด MO จากผลตรวจ AM/PM" (อาการ = ประเภทแท็ก ห้าม 'อื่นๆ')
