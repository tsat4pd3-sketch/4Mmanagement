## ต้นเหตุเชิงระบบ (แก้ที่ต้นทาง ไม่ใช่รายหน้า)
1. **ไม่มีกรอบหน้ากลาง** → `<Page>` + `.page-content` (มีอยู่แล้วแต่ใช้แค่ 14 หน้า)
2. **ธีมตั้ง `select{width:100%}`** → select ที่ไม่ใส่ width ในแถว flex ยืดเต็มแถว → `.filter-bar select{width:auto}`
3. **TimeRangeBar ใช้ขนาดของตัวเอง (29px)** ต่างจากช่องของหน้า → ย้ายไปใช้ token `--ctl-*` เดียวกัน
4. **ไม่มีทะเบียนคำ** → `filterLabels.js`

## ตัดสินใจระหว่างทาง
- **มุมการ์ด 8 กับ 12 ไม่ใช่ความไม่สม่ำเสมอ** — เป็น token `--r-md` / `--r-lg` ที่ตั้งใจ (คอมเมนต์ index.css 22/09 ห้าม sweep มุมทั้งระบบ) ⇒ ไม่กวาด
- **แท็บเกิน 7 ไม่ตัดทิ้ง/ไม่แยกหน้า** — พับเข้า "⋯ เพิ่มเติม" ใน PageHeader (URL เดิมใช้ได้หมด)
- **ชิป "ส่วนงาน:" ในแท็บงานค้างของ OBEYA** = เลือกมุมมองของฝ่าย (?dept=) ไม่ใช่ขอบเขตองค์กร ⇒ เปลี่ยนคำเป็น "มุมมอง:" (คำว่าส่วนงานในระบบ = PD1–PD4)
- ฟอร์มบันทึก (ใน modal) ยังใช้ขนาดตั้งต้นของธีม (~39px = Carbon medium) — มาตรฐาน 34px ใช้กับ **แถบกรอง** เท่านั้น
