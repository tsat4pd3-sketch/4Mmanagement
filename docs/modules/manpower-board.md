## กฎ (ห้าม regress — มีเทสคุม)
- **แถวของคน = ตำแหน่ง** (`levelOfPosition`): `manager`/`section_head` → หัวผัง (แม้จะผูก node ระดับแผนก เช่น "ทั่วไป") ·
  `engineer`/`staff` → แถววิศวกร·เจ้าหน้าที่ · `supervisor` → หัวหน้าแผนก · `leader` → หัวหน้ากลุ่มของคอลัมน์ทีม ·
  `technician` → ช่างประจำไลน์ · ที่เหลือ = พนักงาน · **ตำแหน่งที่ระบบไม่รู้จัก = ลงแถวพนักงาน + ⚠️ ห้ามหาย**
- **หน่วยของคน = `org_node_id`** เดินขึ้นหาแผนก · ไม่มี node ค่อยเทียบ `employees.section` แบบ text · คนที่ผูกระดับส่วนงานตรงๆ = กล่อง "ไม่ระบุแผนก"
- **คอลัมน์ = ทีม (A/B/C)** · กะวันนี้ของทีม = `shiftFromTeam(scheduleTeamFor())` **ห้ามเขียน "A = Shift 01"** (A/B หมุนรายสัปดาห์)
  · บอร์ดจึงเขียน "ทีม A · กะเช้าวันนี้" แทนเลข Shift 01/02 ของกระดาษ
- **ช่องว่าง = std ของกะ − พนักงานในทะเบียนของทีมที่เข้ากะนั้น** (ไม่ใช่คนที่มาวันนี้ — กระดาษก็นับแบบนี้: คนลายังมีการ์ดแขวน)
  ลงที่คอลัมน์ทีมหมุนกะ (A/B) ของกะนั้น · std อ่านผ่าน `stdCapacityOf` ทั้งครอบครัวไลน์ของแผนก (ไม่นับแม่-ลูกซ้ำ)
  · 🔴 **ตารางกะยังไม่ตั้ง = ไม่รู้ว่าทีมไหนเข้ากะไหน ⇒ `slots: null` + แถบเตือน** · std ไม่ได้ตั้ง = แผน `null` เขียน "ยังไม่ตั้ง std" ไม่ใช่ 0
- **ไลน์ของแผนก** = `org_nodes(kind='line').ref_line_id` ใต้แผนก + `line_id` ของคนในแผนก → ขยายเป็นครอบครัว (`lineFamilyOf` รับได้ทั้ง id/ชื่อ)
- **4M ผิดปกติ** = มีใบ 4M วันนี้ที่ **ไม่ถูก reject** ในไลน์ของแผนก (ใบรออนุมัติ นับ + บอกจำนวนที่รอ) · แผนกไม่ผูกไลน์ = "ไม่รู้" (เทา) ไม่ใช่ "ปกติ"
  · ⚠️ ใบ 4M Man อัตโนมัติ (คนใหม่ลงจุด) ก็ทำให้ MAN ผิดปกติ — ตั้งใจ (คือการเปลี่ยนแปลงจริง)
- **ผัง LAYOUT**: คนต่อจุด = จุดประจำ ∪ ที่ถูกจัดวันนี้ · ย้ายมาวันนี้ = ขอบประ ✳ · จุดประจำแต่วันนี้ไปจุดอื่น = จาง ↗ · ลา/ขาด = จาง
  · ขนาดวงจาก `markerScale` · พิกัด % ของรูปจริงผ่าน `useImgBox` (มาตรฐานเดียวกับ LineSetup/Management)
- สด: `useLiveBoard` บน `daily_production_logs` + `four_m_logs` (client Main) · master (ผัง/พนักงาน/skill) โหลดครั้งเดียว
