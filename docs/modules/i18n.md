# 🌐 ปุ่มสลับ ไทย/English — ชั้นภาษาของโครงหลัก (2026-11-02)

> กฎข้าม session อยู่ `docs/UI-CONVENTIONS.md` §6.34 · ไฟล์นี้ = เหตุผล · ขอบเขต · วิธีต่อยอด · กับดัก

## ที่มา
- user ได้รับ comment ว่า UX/UI "ไม่ professional" (ฟอนต์ · สี · layout · template) → สำรวจแล้ว (ภาพ 16 จอ + ตัวเลข:
  emoji 11,384 จุด/277 ไฟล์ · `--font-display` = Tahoma · hex ดิบ 4,218 จุด · น้ำหนัก 700–900 กว่า 3,600 จุด)
- user เลือกเริ่มจาก **"ทำปุ่มสลับ ไทย/Eng · แปลโครงหลักก่อน · ยังไม่ยุ่งธีม"** — งานธีม/ไอคอนรอคำสั่งรอบถัดไป

## ออกแบบ — ทำไมเป็น `tr()` ที่จุดวาด ไม่ใช่ i18n library + คีย์อังกฤษ
- ระบบมีข้อความไทยฝังในโค้ด **~198,000 token** · ไม่มีชั้นภาษาเลย · ชื่อหมวด/เมนูเป็น "คีย์" ที่สิทธิ์ (`permission_catalog.group_name`) ·
  `alsoIn` · `NAV_GROUP_META` · `nav_groups` ใน DB อ้างถึงด้วย **ข้อความไทยตรงตัว** ⇒ เปลี่ยนเป็นคีย์อังกฤษ = แตะทะเบียนสิทธิ์ทั้งระบบ
- ⇒ ข้อความไทย **คือคีย์** · พจนานุกรม `ไทย → English` ไฟล์เดียว · แปลตอน render ด้วย `tr()` · ไทย = ทางด่วนคืนค่าเดิม
  ⇒ **จอไทยเหมือนเดิมทุกพิกเซล** (ตรวจแล้ว: `npm test` 3808 ผ่าน · ภาพ 6 จอโหมดไทยไม่เปลี่ยน)
- emoji นำหน้าป้ายมีทั่วระบบ ⇒ `tr()` ตัด emoji ออกก่อนค้นและประกอบคืน — คีย์เดียวใช้ได้ทุกไอคอน

ข้อความทั่วไป 5,179 · คีย์ที่ผ่าน `tr()` แล้วแต่ไม่มีคำแปล 286

**หลังแก้:** ปุ่ม 290 · หัวตาราง 33 · placeholder 4 · label 3 (ที่เหลือ = ป้ายที่ประกอบกับตัวเลข/ข้อมูล mock) · คีย์ขาด 85 (ล้วนเป็นข้อความประกอบตัวเลข)

template literal (`${}`) — JS พัง · (4) คีย์ซ้ำใน `en.js` = lint `no-dupe-keys` ล่ม · ด่าน `i18n-chrome-literal` กันเขียนดิบกลับมา

## รอบ 3 — ข้อความทั่วไป · tooltip · prop label/sub/hint (2026-11-13 · user: *"ลุยข้อความทั่วไปที่เหลือต่อเลย"*)

**วัดก่อนแก้** (harness ทุกหน้า โหมด EN หลังรอบ 2): text node ไทยนอกปุ่ม/หัวตาราง/option **5,087** · `title=` ไทย **2,577** · คีย์ผ่าน `tr()` แล้วไม่มีคำแปล 1,027
**ทำ:** codemod 2 รอบ (สคริปต์ใช้ครั้งเดียว ไม่เก็บในรีโป)
- รอบ 3: ข้อความไทยที่อยู่ระหว่าง `>`/`}` กับ `<`/`{` บนบรรทัดเดียว (span/div/p/td/b/li …) · `title|label|sub|hint|help|desc|emptyText="…"` ·
  `<tag>{x.label|desc|hint}</tag>` → **7,900 จุด / 286 ไฟล์ · 6,168 คีย์**
- รอบ 3b: สตริงไทยใน ternary/fallback (`? 'ก' : 'ข'` · `|| 'ก'` · `&& 'ก'`) ของ `title={…}`/`label={…}` และ child expression `{…}` → **620 จุด / 135 ไฟล์**
- พจนานุกรม **+6,350 คำ** (`en.js` หมวด "รอบ 3" + "รอบ 3b" · รวม ~8,900 คีย์ · chunk `i18n-*.js` ≈ 820 KB — โหลดครั้งเดียวต่อ session)
**หลังแก้:** text ไทย 3,789 (ในนั้น ~2,150 = ข้อมูล mock/ชื่อไลน์/ชื่อคน · ที่เหลือ = `label:` ของ map คงที่ที่วาดผ่านตัวแปร · ข้อความหลายบรรทัด · template literal) ·
`title=` 1,769 (ส่วนใหญ่ประกอบตัวเลข/ข้อมูล) · คีย์ขาด 92 (ล้วนประกอบตัวเลข เช่น `ทุกไลน์ (3)`) · ปุ่ม 216 · หัวตาราง 23 · placeholder 2
**กับดักรอบนี้ (เพิ่มจากรอบ 2):**
- (1) ห้ามให้ codemod จับ segment ที่ลงท้ายบรรทัด (`$`) — จะกินโค้ด JS ที่มี `}` นำหน้า (เช่น `useState({}); // ไทย`) · ต้องเช็คว่า `'`/`` ` ``/`"` ก่อนตำแหน่งนั้นเป็นจำนวนคู่ (ไม่อยู่ในสตริง)
- (2) 🔴 **ใบพิมพ์ที่สร้างเป็น HTML string ใน template literal (`Report.jsx` ใบ OT) ห้ามครอบ `tr()`** — `{tr('ช')}` จะพิมพ์ออกกระดาษตรงตัว (บั๊กรอบ 2 แก้แล้ว 13/11 · ด่าน `i18n-chrome-literal` มี allow พร้อมเหตุผล)
- (3) ด่านเดิมที่ grep ข้อความไทยตรงตัว (`PageHeader title=` · `'ล้างตัวกรอง'` · `ปิดรายการที่ {endStr` · `<ScanModal title=`) ต้องรับรูป `{tr('…')}` ด้วย — แก้ที่ด่าน ไม่ใช่ถอดด่าน
- (4) คีย์ที่มีอยู่แล้วแต่เขียนคนละรูป (เช่น `'เดือน'`) ⇒ lint `no-dupe-keys` — ลบบรรทัดซ้ำในหมวดใหม่ ห้ามแก้ของเดิม
**ยังไทย (รอบถัดไป ต้องให้ user สั่ง):** `label:` ใน map คงที่ (`STATUS_META` ฯลฯ) ที่วาดผ่าน `{meta.label}` ของตัวแปร · ข้อความหลายบรรทัด · ป้ายประกอบตัวเลข (ต้องแยก badge) ·
วันที่/เดือนไทย · ข้อมูลที่คนกรอก **ไม่แปล**

## วิธีต่อยอด (รอบถัดไป — ต้องให้ user สั่ง)
1. แท็บของหน้าอื่น: เติมเนื้อคำของ `label:` ลง `en.js` (PageHeader แปลให้เองอยู่แล้ว · ไม่ต้องแก้หน้า)
2. ปุ่มมาตรฐานในหน้า (บันทึก/ยกเลิก/Export): ต้องแก้หน้าให้เรียก `tr('บันทึก')` — ทำทีละหน้าตามที่คนนอกเห็นบ่อย
3. วันที่/ตัวเลข: `fmtDateTime`/`th-TH` ยังไทย · ถ้าทำให้อ่าน `getLang()` ต้องระวัง **พ.ศ./ค.ศ.** (เอกสารพิมพ์ยึด พ.ศ.)
4. ข้อความที่คนกรอก (ชื่อไลน์ · อาการเสีย · หมายเหตุ) **ไม่แปล** — เป็นข้อมูล ไม่ใช่ UI

## กับดักที่เจอตอนทำ
- ด่าน `regressionGuards` "ห้ามวาดปุ่มล้างตัวกรองเอง" grep คำ `'ล้างตัวกรอง'` ทั้ง `src/` ⇒ เจอในพจนานุกรม · แก้ที่ด่านให้ข้าม `src/i18n/` (พจนานุกรมถือคำเป็นคีย์ ไม่ใช่ปุ่ม)

- "วัน" หลังตัวเลขภาษาอังกฤษต้องผันพหูพจน์ (`30 days` / `1 day`) ⇒ `unitDays(n)` ไม่ใช่ `tr('วัน')`
