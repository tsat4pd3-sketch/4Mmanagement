## ออกแบบ — ทำไมเป็น `tr()` ที่จุดวาด ไม่ใช่ i18n library + คีย์อังกฤษ
- ระบบมีข้อความไทยฝังในโค้ด **~198,000 token** · ไม่มีชั้นภาษาเลย · ชื่อหมวด/เมนูเป็น "คีย์" ที่สิทธิ์ (`permission_catalog.group_name`) ·
  `alsoIn` · `NAV_GROUP_META` · `nav_groups` ใน DB อ้างถึงด้วย **ข้อความไทยตรงตัว** ⇒ เปลี่ยนเป็นคีย์อังกฤษ = แตะทะเบียนสิทธิ์ทั้งระบบ
- ⇒ ข้อความไทย **คือคีย์** · พจนานุกรม `ไทย → English` ไฟล์เดียว · แปลตอน render ด้วย `tr()` · ไทย = ทางด่วนคืนค่าเดิม
  ⇒ **จอไทยเหมือนเดิมทุกพิกเซล** (ตรวจแล้ว: `npm test` 3808 ผ่าน · ภาพ 6 จอโหมดไทยไม่เปลี่ยน)

**กับดักรอบนี้:**

- (2) template literal ใน `<style>{\`…\`}` มีคอมเมนต์ไทย — codemod จับเป็นข้อความ ⇒ ต้องข้าม raw ที่มี `/*` · `@media` · `.class {`
- (3) class C ต้องใช้ `node.extra.raw` ไม่ใช่ `node.value` — สตริงที่มี `\n` จะกลายเป็นขึ้นบรรทัดจริงในซอร์ส (Unterminated string 9 ไฟล์)

- (5) ด่านที่ grep ไทยตรงตัว (`ยังไม่ลงถัง {pend.length}` · `แยกตามชิ้นงาน …` · `+ อีก ` · `รับของสำเร็จ ${ok} จาก` · `ซ่อนอยู่ ${hidden}` · matOrderSweep allow `ผูกกับ MAT SAP:`) → รับรูป `tr("…")}` (แก้ที่ด่าน 6 จุด ห้ามถอด)
- (7) 🔴 **JSXText ที่มี HTML entity (`&quot;` `&gt;` `&ldquo;`)** — babel `node.value` decode entity แล้ว แต่ `node.start` ชี้ raw ⇒ offset เพี้ยนเท่าความยาว entity
  เจอจริง 5/11 จุด (`mo=&q{tr(` · `")}&quot; ที่` · คำท้ายซ้ำ `")}ันที`) แก้มือแล้ว · ด่านใหม่ `i18n-entity-fragment` · codemod ครั้งหน้าใช้ `node.extra.raw`
- (6) `en.js` มีคีย์ไทยแบบ **ไม่ใส่ quote** (`วัน: 'day'`) — regex หาคีย์เดิมต้องรับรูปนี้ด้วย ไม่งั้น `no-dupe-keys` (วัน/เดือน/ปี/สัปดาห์)

## 🖨️ กับดักที่ทำใบพิมพ์พังทั้งระบบ — `{tr()}` ในสตริง HTML (2026-11-17 · หน้างานส่งใบจริงมา)

ใบ MO ที่พิมพ์ออกมาให้ ผจก. เซ็น ขึ้นข้อความดิบเต็มใบ:
`{trI18n('บริษัท ไทยซัมมิท โอโตโมทีฟ จำกัด')}` · `{trI18n('ค่าอะไหล่และอุปกรณ์')}` · `{trI18n('ลำดับ')}` …

**ต้นเหตุ:** codemod i18n ห่อข้อความไทยด้วยท่า **JSX** `{trI18n('…')}` ทั้งรีโป
แต่**ใบพิมพ์ทุกใบประกอบ HTML ด้วย template literal** (`const html = \`<!DOCTYPE html…\``)
⇒ ในสตริงต้องเป็น **`${trI18n('…')}`** · ปีกกาเดี่ยวถูกพิมพ์ออกมาเป็นตัวหนังสือบนกระดาษ

🔴 **ไม่ใช่แค่ใบ MO — วัดแล้ว 136 จุด ใน 10 ไฟล์:**
`Report.jsx` (มากสุด) · `MtnRepair.jsx` · `LayerProcessAudit.jsx` · `OjtTraining.jsx` ·
`EventLog.jsx` · `MorningMeeting.jsx` · `PmCoordination.jsx` · `KpiMonthly.jsx` · `RackCenter.jsx`

**ด่าน `print-html-needs-dollar-tr`** — จับบรรทัดที่มี **HTML แท้** แล้วมี `{tr(`/`{trI18n(` ไม่มี `$` นำหน้า
🔑 สัญญาณที่ใช้ได้จริง = `class="` · `style="` · `colspan=` · `rowspan=` · `<!doctype`
  (JSX เขียน `className` · `colSpan` · `style={{…}}` ⇒ ไม่ชนกัน)
🔴 **ห้ามใช้ `<td`/`<th` เป็นสัญญาณ** — เคยลองแล้ว match JSX ทั้งรีโป ด่านเสียงดังจนใช้ไม่ได้

**บทเรียนข้ามรอบ:** codemod ที่กวาดทั้งรีโปต้องแยก "ไฟล์ที่เป็น JSX" กับ "สตริงที่ประกอบ HTML"
ออกจากกันก่อนเสมอ — build/lint/เทสผ่านหมด **เห็นได้จากกระดาษที่พิมพ์ออกมาเท่านั้น**
