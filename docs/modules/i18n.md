# 🌐 ปุ่มสลับ ไทย/English — ชั้นภาษาของโครงหลัก (2026-11-02)

> กฎข้าม session อยู่ `docs/UI-CONVENTIONS.md` §6.34 · ไฟล์นี้ = เหตุผล · ขอบเขต · วิธีต่อยอด · กับดัก

## ที่มา
- user ได้รับ comment ว่า UX/UI "ไม่ professional" (ฟอนต์ · สี · layout · template) → สำรวจแล้ว (ภาพ 16 จอ + ตัวเลข:
  emoji 11,384 จุด/277 ไฟล์ · `--font-display` = Tahoma · hex ดิบ 4,218 จุด · น้ำหนัก 700–900 กว่า 3,600 จุด)
- user เลือกเริ่มจาก **"ทำปุ่มสลับ ไทย/Eng · แปลโครงหลักก่อน · ยังไม่ยุ่งธีม"** — งานธีม/ไอคอนรอคำสั่งรอบถัดไป

## ออกแบบ — ทำไมเป็น `tr()` ที่จุดวาด ไม่ใช่ i18n library + คีย์อังกฤษ
- ระบบมีข้อความไทยฝังในโค้ด **~198,000 token** · ไม่มีชั้นภาษาเลย · ชื่อหมวด/เมนูเป็น "คีย์" ที่สิทธิ์ (`permission_catalog.group_name`) ·
  `alsoIn` · `NAV_GROUP_META` · `nav_groups` ใน DB อ้างถึงด้วย **ข้อความไทยตรงตัว** ⇒ เปลี่ยนเป็นคีย์อังกฤษ = แตะทะเบียนสิทธิ์ทั้งระบบ
- ⇒ ข้อความไทย **คือคีย์** · พจนานุกรม `ไทย → English` ไฟล์เดียว · แปลตอน render ด้วย `tr()` · ไทย = ทางด่วนคืนค่าเดิม
  ⇒ **จอไทยเหมือนเดิมทุกพิกเซล** (ตรวจแล้ว: `npm test` 3808 ผ่าน · ภาพ 6 จอโหมดไทยไม่เปลี่ยน)
- emoji นำหน้าป้ายมีทั่วระบบ ⇒ `tr()` ตัด emoji ออกก่อนค้นและประกอบคืน — คีย์เดียวใช้ได้ทุกไอคอน

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `src/utils/i18n.js` | `getLang/setLang/nextLang` · `tr(str)` · `trMissing()` · `allLabel()` · `unitDays(n)` · ไม่ import react |
| `src/utils/useLang.js` | `LangProvider` (ครอบ `<App/>` ใน `main.jsx`) · `useLang()` → `{lang, setLang, toggleLang, tr}` · `langToggleLabel/Title` · ไม่มี Provider (harness) = fallback + reload |
| `src/i18n/en.js` | พจนานุกรม — หมวด/เมนู/ชื่อหน้า/คำอธิบาย/แท็บหน้าตัวอย่าง/ALL/timeRange/sidebar/Home |
| `src/utils/__tests__/i18n.test.mjs` | ด่าน: สัญญาของ `tr()` + โครงหลักต้องมีคำแปลครบ |

จุดที่ต่อ `tr()` แล้ว: `App.jsx` (Sidebar · `<Router key={lang}>`) · `PageHeader` · `TimeRangeBar` · `Segmented` · `ClearFiltersBtn` ·
`MobileNavBar` · `filterLabels.js` (`ALL` เป็น getter · `allOf` → `allLabel`) · `profileMenu.js` (แถว toggle `lang`) · `DeptHub.jsx`

## วิธีต่อยอด (รอบถัดไป — ต้องให้ user สั่ง)
1. แท็บของหน้าอื่น: เติมเนื้อคำของ `label:` ลง `en.js` (PageHeader แปลให้เองอยู่แล้ว · ไม่ต้องแก้หน้า)
2. ปุ่มมาตรฐานในหน้า (บันทึก/ยกเลิก/Export): ต้องแก้หน้าให้เรียก `tr('บันทึก')` — ทำทีละหน้าตามที่คนนอกเห็นบ่อย
3. วันที่/ตัวเลข: `fmtDateTime`/`th-TH` ยังไทย · ถ้าทำให้อ่าน `getLang()` ต้องระวัง **พ.ศ./ค.ศ.** (เอกสารพิมพ์ยึด พ.ศ.)
4. ข้อความที่คนกรอก (ชื่อไลน์ · อาการเสีย · หมายเหตุ) **ไม่แปล** — เป็นข้อมูล ไม่ใช่ UI

## กับดักที่เจอตอนทำ
- ด่าน `regressionGuards` "ห้ามวาดปุ่มล้างตัวกรองเอง" grep คำ `'ล้างตัวกรอง'` ทั้ง `src/` ⇒ เจอในพจนานุกรม · แก้ที่ด่านให้ข้าม `src/i18n/` (พจนานุกรมถือคำเป็นคีย์ ไม่ใช่ปุ่ม)
- `allOf('ขั้น')` ได้ `All ขั้น` ถ้าคำนามไม่มีในพจนานุกรม — ป้ายผสมภาษา ⇒ คำนามที่ใช้กับ `allOf` ต้องมีคำแปลด้วย
- "วัน" หลังตัวเลขภาษาอังกฤษต้องผันพหูพจน์ (`30 days` / `1 day`) ⇒ `unitDays(n)` ไม่ใช่ `tr('วัน')`
- ชื่อย่อ rail 64px: `Maintenance` ถูกตัด ⇒ `Maint.`
- harness `audit/*.html` ไม่มี `LangProvider` ⇒ `useLang()` ต้องมี fallback (ไม่งั้นครบทุกหน้าพังใน crashsweep)
