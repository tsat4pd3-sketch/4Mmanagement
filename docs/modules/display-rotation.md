## กฎ

- 🔴 **หน้าตั้งค่าให้เลือกได้เฉพาะหน้าที่บัญชีนั้นเข้าได้** (09/10 · user: *"หน้าที่เข้าไม่ได้ก็ไม่ควรมีให้ setup"*)
  — ตัวเลือกกรองด้วย `canAccessPage(to, role ของบัญชี)` · จอเขียนว่า "ซ่อน N หน้าที่ไม่มีสิทธิ์" ·
  แถวเก่าที่สิทธิ์ถูกถอดทีหลังยังโผล่พร้อม ⛔ + path และ **บันทึกไม่ได้จนกว่าจะเอาออก**
- 🔴 **หน้าที่บัญชีจอไม่มีสิทธิ์ = ข้าม แล้วต้องเขียนบนจอ** (ด่านชั้นสอง — สิทธิ์ถูกถอดหลังตั้งรอบ) — ชิปบนจอ "⚠ ข้าม N หน้า" (hover ดูรายการ) +
  หน้าตั้งค่าติด ⛔ ตั้งแต่ตอนเลือก · ตัดสินด้วย `canAccessPage(path, role ของบัญชีนั้น)` ตอนวนจริง
  **ห้ามเก็บสิทธิ์ลงแถว** (สิทธิ์เปลี่ยนที่ `/permissions` ได้ตลอด)
- 🔴 **ตัววนไม่ยกเว้น auto-logout** — เปลี่ยนหน้าเองไม่นับเป็น activity · บัญชีจอควรเป็น role `display`
  (ยกเว้น idle-logout อยู่แล้ว) · หน้าตั้งค่าเตือนเหลืองเมื่อบัญชีไม่ใช่ display
  · **ห้ามแก้ด้วยการเพิ่มทุกหน้าในรอบเข้า `KIOSK_PATHS`** (กฎใน `src/utils/kioskRoutes.js` — หน้าที่มีปุ่มเขียนข้อมูลห้ามเป็น kiosk)
- path ต้องเป็นเส้นทางภายใน (`/…` · ห้าม `//host` `http:` · ห้าม `/login` `/register`) — `isValidRotationPath()`
- มีคนแตะ/คลิก/กดปุ่ม/เลื่อน = หยุดวนชั่วคราว `pause_sec` แล้ววนต่อเอง · ปุ่ม ⏸ บนชิป = หยุดค้าง
  (ปุ่มบนชิปเองไม่นับเป็น "มีคนใช้จอ")
- เปลี่ยนหน้าแบบ SPA · ครบ `reload_min` แล้ว **รีโหลดเต็มหน้าตอนเปลี่ยนหน้า** (`window.location.assign` ไปหน้าถัดไป)
  กันหน่วยความจำค้างบนทีวี webOS (Chromium 94) · `null` = ไม่รีโหลด
- อ่านแผนใหม่ทุกครั้งที่วนครบรอบ (1 แถวเล็ก) — **ไม่ใช้ realtime** · แก้ที่หน้าตั้งค่าแล้วจอรับเองภายใน 1 รอบ
- admin ที่จำลองมุมมอง (viewAs) = ตัววนปิด
- จอที่ login บัญชีเดียวกันหลายเครื่อง = ได้รอบเดียวกัน (ผูกต่อบัญชี ไม่ใช่ต่อเครื่อง) — อยากให้ต่างกันต้องแยกบัญชี

## 🐛 19/10 — ทีวีค่อยๆ ย่อจอลงเรื่อยๆ (เห็นชัดหลังสลับผังโรงงาน 3D → 2D)
- ต้นเหตุ: `fit()` เดิมคิด `target = zoom × ความสูงจอ ÷ rect.height` โดยเชื่อว่า rect "คูณ zoom แล้ว" — จริงเฉพาะ
  Chromium 128+ · **Chromium 94 (webOS) คืน rect ของตัวที่ตั้ง zoom เป็นขนาดก่อนย่อ** ⇒ ทุก 1.5 วิ target เล็กลงทบไปเรื่อยๆ จนชน 55%
  (3D มี `data-tv-nofit` = รีเซ็ตเป็น 1 · กลับ 2D = เริ่มย่อทบใหม่ ⇒ คนเห็นตอนสลับ) · เครื่อง dev เป็น Chromium ใหม่ = จำลองไม่เจอ
- แก้: ถอด zoom → วัดความสูงจริง → ใส่คืน (จังหวะเดียว ไม่มี paint คั่น) แล้ว `target = จอ ÷ ความสูงนั้น` ไม่คูณ zoom ปัจจุบัน
  · จำลองพฤติกรรม Cr94 ใน harness: สูตรเดิม 0.96→0.92→…→0.58 · สูตรใหม่นิ่ง 0.96 · ด่าน `tv-fit-no-compound-zoom`
- 🔴 **โค้ดที่อ่านขนาดของ element ที่ตั้ง CSS `zoom` ห้ามพึ่งว่า rect คูณ zoom แล้วหรือยัง** — 2 รุ่นเบราว์เซอร์ตอบต่างกัน
