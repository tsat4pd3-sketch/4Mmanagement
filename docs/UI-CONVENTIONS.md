# UI Conventions — กติกากลางของทุกหน้า UI

> **อ่านไฟล์นี้ก่อนแก้ UI ทุกครั้ง และทำตามอย่างเคร่งครัด**
> ถ้างานที่ทำสร้าง/เปลี่ยน pattern ที่ใช้ร่วมกันหลายหน้า ต้องอัพเดทไฟล์นี้ (พร้อมวันที่) **ในคอมมิทเดียวกัน**
> ถ้า convention ขัดกับสิ่งที่กำลังจะทำ → ทำตาม convention ก่อนเสมอ เว้นแต่เจ้าของโปรเจกต์สั่งเปลี่ยน

---

## 1. จุด/Marker บนผังไลน์ (ทุกหน้า: Dashboard, Management, LineSetup) — 2026-07-09

- **รูปทรงเดียวที่อนุญาต: วงกลม + ป้ายชื่อใต้วงกลม** — ห้ามกล่องสี่เหลี่ยม
  (จุดคน, จุดเครื่องจักร, จุด WIP ต้องหน้าตาเป็นระบบเดียวกัน ต่างกันที่ไอคอน/สีวงแหวน)
- **ขนาดใช้สูตร MK** — สเกลตามความกว้างของ "ตัวรูปผังจริง" (หลังหัก letterbox จาก objectFit:contain)
  ไม่ใช่ค่าคงที่ px และไม่ใช่ % ของ viewport:
  ```
  markerPx = clamp(MIN, mapRenderWidth × RATIO, MAX)
  ผังขยายเต็มจอ: MIN 48 / RATIO 0.06 / MAX 84   (เทียบเท่า clamp(48px, 6vw, 84px) เดิม)
  ผังย่อ (thumbnail): MIN 22 / RATIO 0.05 / MAX 34
  ```
- **ตำแหน่งต้อง clamp ไม่ให้ตกขอบรูป**: `left/top = clamp(pos%, markerHalf, 100% − markerHalf)`
  marker ที่พิกัดชิดขอบต้องยังเห็นเต็มวง ไม่โดนรูปตัด
- พิกัดเก็บเป็น % ของตัวรูปจริง (`pos_top`/`pos_left`) — มาตรฐานเดียวกับ LineSetup/Management/Dashboard

## 2. ไฟ/ป้าย Alarm — ตรรกะ Andon เขียว-เหลือง-แดง — 2026-07-09

| สี | ความหมาย | พฤติกรรม |
|---|---|---|
| 🟢 เขียว | ปกติ / ทำงานอยู่ | นิ่ง |
| 🟡 เหลือง | ต้องสนใจ (รออนุมัติ 4M, เกินเวลา, ใกล้ครบกำหนด) | **นิ่ง** (เรืองแสงได้ ห้ามกระพริบ) |
| 🔴 แดง | เครื่องหยุดค้าง / NG / PPE ไม่ครบ — ต้องหยุดดูเดี๋ยวนี้ | **กระพริบ** (เฉพาะสีแดงเท่านั้นที่กระพริบ) |

- CSS กลาง: `.person-alarm-red` (กระพริบ), `.person-alarm-amber` (นิ่ง+เรืองแสง), `.dt-alarm-blink`,
  `.dt-alarm-banner`, `.dt-alarm-icon` — ใช้ของกลาง ห้ามเขียน keyframes ใหม่ต่อหน้า
- Downtime เครื่องจักร: กระพริบเฉพาะตอน "รายการยังเปิดค้าง" (เครื่องยังหยุดจริง) — ปิดรายการ = ดับทันที
  (`src/utils/downtimeAlarm.js` เป็น source of truth ห้ามเพิ่มเงื่อนไขเวลาอื่น)

## 3. เส้นบอกเวลาปัจจุบันบนไทม์ไลน์ (playhead) — 2026-07-09

- ใช้ CSS กลาง `.now-line` (เส้นชมพู #ec4899 + หัวลูกศร + pulse) และ `.now-chip` (ป้ายเวลาลอยบนหัวตาราง)
- สีชมพูสงวนไว้สำหรับ playhead เท่านั้น — ห้ามใช้กับสถานะงาน
- บอร์ดไทม์ไลน์ใหม่ทุกตัวต้องมีทั้งเส้นและป้ายเวลา

## 4. บอร์ด Heijunka / ไทม์ไลน์ 2 กะ — 2026-07-09

- โครง "พาร์ทละ 1 บล็อก": ป้าย+รูปพาร์ทใหญ่ 1 อันครอบ 2 แถบเวลา (☀️ 08–20 บน / 🌙 20–08 ล่าง)
  หัวชั่วโมงแสดงเวลาคู่บน-ล่างในคอลัมน์เดียวกัน — ห้ามกลับไปวาดแยกบล็อกเช้า/ดึกซ้ำป้าย
- Downtime/สาเหตุดีเลย์ต้องผูกกับ sub-line ของใบงานนั้น (`line_name`) ห้ามจับคู่ด้วยเวลาอย่างเดียว

## 5. ฟอนต์ & ขนาด (จอ TV/บอร์ดหน้างาน) — 2026-07-09

- **ขั้นต่ำ 11–12px** สำหรับชิป/ป้าย/ข้อความรอง, 14–15px สำหรับหัวข้อ — ห้าม 8–9px ทั้งที่พื้นที่เหลือ
- ข้อยกเว้นเดียว: ตัวเลขในใบกัมบัง/ช่องไทม์ไลน์ที่พื้นที่บังคับจริงๆ (แต่ tooltip ต้องมีข้อมูลเต็ม)
- การ์ดใน grid เดียวกันต้องสูงเท่ากัน (ใช้ grid + ให้เนื้อหายืด ไม่ปล่อยการ์ดเตี้ยสูงสลับกัน)

## 6. สิทธิ์การกด/แก้ไข (action permission) — 2026-07-09

- ใช้ `can()` / `hasPermission()` จาก `src/utils/permissions.js` เท่านั้น
- **ห้ามเพิ่ม hardcode role array ใหม่** (`['admin','manager',...].includes(role)`) — ของเก่าที่ยังค้างให้ทยอยแทนที่เมื่อแตะไฟล์นั้น
- แยกให้ถูก: permission = "ทำ action นี้ได้ไหม" / scoping (section/line/team) = "เห็นข้อมูลแถวไหน" — คนละกลไก

## 7. กับดัก CSS ระดับแอป (ดูรายละเอียดใน CLAUDE.md ด้วย) — 2026-07-09

- `input, select, textarea { width: 100% }` เป็น default ทั้งแอป → input ใน flex/toolbar แนวนอน**ต้องตั้ง width เอง**
- checkbox/radio มี rule ยกเว้นเป็น `width: auto` แล้ว — ห้ามลบ rule นี้
- อย่าลืม: แก้ pattern ที่ใช้ร่วมกันหลายหน้า → อัพเดทไฟล์นี้ในคอมมิทเดียวกัน
